# 四层架构依赖规范

## 依赖层级原则

严格遵循**单向依赖、上层依赖下层**的原则，严禁反向耦合。

---

## 依赖层级图

```
        ┌─────────────────┐
        │  第4层:验证     │
        │  (validation)  │
        └────────┬────────┘
                 │ 依赖
        ┌────────▼────────┐
        │  第3层:原子     │
        │  (atomic_actions)│
        └────────┬────────┘
                 │ 依赖
        ┌────────▼────────┐
        │  第2层:拓扑     │
        │   (topology)   │
        └────────┬────────┘
                 │ 依赖
        ┌────────▼────────┐
        │  第1层:建模     │
        │ (task_modeling)│
        └─────────────────┘
```

---

## 各层职责与依赖范围

### 第1层：任务建模层 (`task_modeling`)
**职责**: 标准Task四元组定义、需求解析、目标提取、条件识别等

**依赖范围**:
- 仅依赖 Python 标准库
- **不依赖**其他业务层

**模块**:
- `task_struct.py` - 标准数据结构定义
- `parser.py` - 需求解析
- `target_extractor.py` - 目标提取
- `condition_extractor.py` - 条件识别
- `boundary_extractor.py` - 边界提取
- `end_rule_extractor.py` - 结束规则提取
- `task_interceptor.py` - 任务拦截
- `task_validator.py` - 任务验证

---

### 第2层：拓扑依赖拆解层 (`topology`)
**职责**: 子任务拆分、DAG生成、依赖计算、调度标记等

**依赖范围**:
- 依赖 `task_modeling` (第1层)
- **不依赖**第3、4层

**模块**:
- `subtask_node.py` - 子任务节点结构
- `subtask_splitter.py` - 子任务拆分
- `dependency_calculator.py` - 依赖计算
- `dag_generator.py` - DAG生成
- `topology_corrector.py` - 拓扑纠错
- `schedule_marker.py` - 调度标记
- `redundancy_filter.py` - 冗余过滤
- `link_binder.py` - 链路绑定

---

### 第3层：原子动作收敛层 (`atomic_actions`)
**职责**: 动作拆分、原子验证、队列生成、动作净化等

**依赖范围**:
- 依赖 `task_modeling` (第1层)
- 依赖 `topology` (第2层)
- **不依赖**第4层

**模块**:
- `atomic_action_struct.py` - 原子动作结构
- `action_splitter.py` - 动作拆分
- `atomic_validator.py` - 原子验证
- `atomic_queue_generator.py` - 队列生成
- `action_purifier.py` - 动作净化

---

### 第4层：分段校验收敛层 (`validation`)
**职责**: 目标对齐预校验、分段验证、熔断规则、回滚重规划等

**依赖范围**:
- 依赖 `task_modeling` (第1层)
- 依赖 `topology` (第2层)
- 依赖 `atomic_actions` (第3层)

**模块**:
- `segment_validator.py` - 分段验证
- `target_alignment.py` - 目标对齐预校验
- `action_post_validator.py` - 动作执行后校验
- `logger_manager.py` - 日志管理
- `config_manager.py` - 配置管理
- `history_manager.py` - 历史记录管理
- `performance_monitor.py` - 性能监控

---

### 整合层 (`decomposition`)
**职责**: 复杂任务分解引擎（跨层整合）

**依赖范围**:
- 可以依赖所有4层架构模块
- 作为整体系统的整合层

**模块**:
- `complex_task_decomposer.py` - 复杂任务分解引擎

---

## 导入规则

### 同一包内导入
```python
# 正确：相对导入或包内导入
from . import task_struct
from .task_struct import Task
```

### 跨层导入（上层依赖下层）
```python
# 正确：第2层依赖第1层
from task_modeling.task_struct import Task
from task_modeling.parser import parse_task_from_description

# 正确：第3层依赖第1、2层
from task_modeling.task_struct import Task
from topology.subtask_node import SubTaskNode
```

### 严禁反向依赖
```python
# ❌ 错误：第1层依赖第2层
from topology.subtask_node import SubTaskNode  # 严禁！

# ❌ 错误：第3层依赖第4层
from validation.segment_validator import validate  # 严禁！
```

---

## 验收标准

✅ 所有导入符合单向依赖规则  
✅ 无反向耦合  
✅ 第1层不依赖其他业务层  
✅ 第2层只依赖第1层  
✅ 第3层只依赖第1、2层  
✅ 第4层可以依赖第1、2、3层  
✅ 分解整合层可依赖所有层
