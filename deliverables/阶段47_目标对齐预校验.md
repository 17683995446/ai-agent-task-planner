## 📁 交付文件

### 1. `/workspace/src/validation/target_alignment.py`

核心实现文件，包含以下组件：

#### 核心枚举

**`AlignmentStatus` (对齐状态)**
- `ALIGNED`: 完全对齐
- `PARTIAL`: 部分对齐
- `DEVIATED`: 已偏离
- `BLOCKED`: 被阻止

**`DriftType` (偏离类型)**
- `SEMANTIC`: 语义偏离
- `SCOPE`: 范围偏离
- `DIRECTION`: 方向偏离
- `SCALE`: 规模偏离

#### 核心数据类

**`TargetDefinition`**
- 目标定义
- 包含关键词、实体、范围边界、反向关键词

**`AlignmentMetrics`**
- 对齐指标
- 匹配度、偏离度、覆盖率、相关度

**`AlignmentReport`**
- 对齐报告
- 包含指标、偏离检测、警告、建议

#### 核心类

**`TargetAlignmentValidator` (目标对齐验证器)**

| 方法 | 功能描述 |
|------|----------|
| `define_target()` | 定义目标 |
| `validate_alignment()` | 验证目标对齐 |
| `_calculate_alignment_metrics()` | 计算对齐指标 |
| `_detect_drift()` | 检测偏离类型 |
| `_generate_feedback()` | 生成反馈 |
| `validate_with_segment_validator()` | 综合验证 |
| `get_alignment_trend()` | 获取对齐趋势 |

**便捷函数**
- `quick_align_check()`: 快速对齐检查

## 📊 对齐指标体系

### 1. 匹配度 (Match Score)
- **范围**: 0-1
- **计算**: 关键词命中比例
- **阈值**: 默认 0.6
- **低于阈值**: 触发警告

### 2. 偏离度 (Drift Score)
- **范围**: 0-1
- **计算**: 反向关键词命中比例
- **阈值**: 默认 0.3
- **超过阈值**: 触发阻止

### 3. 覆盖率 (Coverage Score)
- **范围**: 0-1
- **计算**: 目标关键词被动作覆盖的比例
- **低于 0.3**: 触发警告

### 4. 相关度 (Relevance Score)
- **范围**: 0-1
- **计算**: (匹配度 + 覆盖率) / 2
- **综合评估**: 动作与目标的相关程度

## 💡 使用示例

### 场景：销售报告生成

```python
from src.validation.target_alignment import (
    TargetAlignmentValidator,
    quick_align_check
)

# 1. 创建验证器
validator = TargetAlignmentValidator(
    match_threshold=0.6,
    drift_threshold=0.3
)

# 2. 定义目标
validator.define_target(
    target_id="sales_report",
    target_text="生成月度销售数据分析报告，包含各区域销售数据和趋势分析",
    scope_keywords=["销售", "分析", "报告", "数据"],
    anti_keywords=["投诉", "退货", "库存"]
)

# 3. 验证每个动作
actions = [
    "读取数据库中的销售记录",
    "按区域统计销售额",
    "生成可视化图表",
    "撰写分析报告",
    "处理客户投诉"  # 这个会触发偏离
]

for action in actions:
    report = validator.validate_alignment(
        target_id="sales_report",
        action_text=action
    )
    
    status = "✅" if not report.should_block else "❌"
    print(f"{status} {action}")
    print(f"   匹配度: {report.metrics.match_score:.2f}")
    
    if report.warnings:
        for warning in report.warnings:
            print(f"   ⚠️ {warning}")

# 4. 获取趋势
trend = validator.get_alignment_trend("sales_report")
print(f"\n对齐趋势: {trend['match_trend']}")
```
