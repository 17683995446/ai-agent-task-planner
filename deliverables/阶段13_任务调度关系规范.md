## 一、三种任务关系概述

### 1.1 关系定义

| 关系类型 | 定义 | 核心特征 | 执行方式 |
|---------|------|---------|---------|
| **串行关系（Serial）** | 任务A必须完成后，任务B才能开始 | 有序性、严格先后 | 依次执行 |
| **并行关系（Parallel）** | 任务A和任务B可以同时执行 | 独立性、无依赖 | 同时执行 |
| **依赖关系（Dependency）** | 任务B需要任务A的输出作为输入 | 输入依赖、数据传递 | 按依赖顺序执行 |

### 1.2 关系对比表

| 维度 | 串行关系 | 并行关系 | 依赖关系 |
|-----|---------|---------|---------|
| **执行顺序** | 严格先后 | 无要求 | 依赖在前 |
| **数据传递** | 可选 | 无 | 必须 |
| **资源竞争** | 无 | 可能 | 无 |
| **可同时执行** | 否 | 是 | 否 |
| **判定依据** | 业务逻辑顺序 | 无依赖 | 输入输出匹配 |

## 二、串行关系判定规则

### 2.1 判定条件

满足以下任意条件之一，两个任务即为串行关系：

| 规则编号 | 规则名称 | 规则描述 | 示例 |
|---------|---------|---------|------|
| **S-1** | 业务顺序 | 业务逻辑要求必须先A后B | 启动→运行→停止 |
| **S-2** | 资源独占 | 任务需要独占某资源 | 文件写入→文件关闭 |
| **S-3** | 状态依赖 | 任务B依赖任务A改变的状态 | 创建会话→使用会话 |
| **S-4** | 上下文连续性 | 任务A为任务B准备上下文 | 数据加载→数据处理 |

### 2.2 判定函数

```python
def is_serial_relation(task_a: TaskNode, task_b: TaskNode) -> bool:
    """
    判定两个任务是否为串行关系
    返回：True 表示串行关系，False 表示非串行关系
    """
    # 规则S-1: 业务顺序
    if has_business_order_dependency(task_a, task_b):
        return True
    
    # 规则S-2: 资源独占
    if has_resource_exclusivity(task_a, task_b):
        return True
    
    # 规则S-3: 状态依赖
    if has_state_dependency(task_a, task_b):
        return True
    
    # 规则S-4: 上下文连续性
    if has_context_continuity(task_a, task_b):
        return True
    
    return False


def has_business_order_dependency(task_a: TaskNode, task_b: TaskNode) -> bool:
    """检查是否存在业务顺序依赖"""
    order_keywords = ['先', '然后', '接着', '之后', '最后']
    b_keywords = ['才能', '才能开始', '必须先']
    
    desc_a = task_a.description.lower()
    desc_b = task_b.description.lower()
    
    for keyword in b_keywords:
        if keyword in desc_b:
            return True
    
    return False


def has_resource_exclusivity(task_a: TaskNode, task_b: TaskNode) -> bool:
    """检查是否存在资源独占依赖"""
    exclusive_resources = ['文件', '锁', '连接', '句柄', '端口']
    
    for resource in exclusive_resources:
        if resource in task_a.description and resource in task_b.description:
            if task_a.output and task_a.output.get('resource') == resource:
                if 'close' in task_b.description or 'release' in task_b.description:
                    return True
    
    return False


def has_state_dependency(task_a: TaskNode, task_b: TaskNode) -> bool:
    """检查是否存在状态依赖"""
    state_keywords = {
        'create': ['use', 'read', 'write', 'update'],
        'open': ['read', 'write', 'close'],
        'start': ['stop', 'pause', 'restart'],
        'init': ['run', 'execute', 'process']
    }
    
    action_a = extract_action_verb(task_a.description)
    action_b = extract_action_verb(task_b.description)
    
    if action_a in state_keywords:
        if action_b in state_keywords[action_a]:
            return True
    
    return False


def has_context_continuity(task_a: TaskNode, task_b: TaskNode) -> bool:
    """检查是否存在上下文连续性"""
    continuity_pairs = [
        ('加载', '处理'), ('加载', '分析'), ('准备', '执行'),
        ('初始化', '运行'), ('配置', '启动')
    ]
    
    for keyword_a, keyword_b in continuity_pairs:
        if keyword_a in task_a.description and keyword_b in task_b.description:
            return True
    
    return False
```

## 三、并行关系判定规则

### 3.1 判定条件

满足以下所有条件，两个任务才为并行关系：

| 规则编号 | 规则名称 | 规则描述 |
|---------|---------|---------|
| **P-1** | 无数据依赖 | 任务A的输出不是任务B的输入 |
| **P-2** | 无资源竞争 | 两个任务不争用同一独占资源 |
| **P-3** | 无状态依赖 | 任务A的执行不影响任务B的状态 |
| **P-4** | 无业务顺序 | 业务逻辑不要求特定执行顺序 |

### 3.2 判定函数

```python
def is_parallel_relation(task_a: TaskNode, task_b: TaskNode) -> bool:
    """
    判定两个任务是否为并行关系
    返回：True 表示并行关系，False 表示非并行关系
    """
    # 必须同时满足所有并行条件
    
    # 规则P-1: 无数据依赖
    if has_data_dependency(task_a, task_b):
        return False
    
    # 规则P-2: 无资源竞争
    if has_resource_contention(task_a, task_b):
        return False
    
    # 规则P-3: 无状态依赖
    if has_state_dependency_cross(task_a, task_b):
        return False
    
    # 规则P-4: 无业务顺序
    if has_business_order_dependency(task_a, task_b) or has_business_order_dependency(task_b, task_a):
        return False
    
    return True


def has_data_dependency(task_a: TaskNode, task_b: TaskNode) -> bool:
    """检查是否存在数据依赖"""
    if not task_a.output or not task_b.input:
        return False
    
    outputs_a = set()
    if isinstance(task_a.output, dict):
        outputs_a = set(task_a.output.keys())
    elif isinstance(task_a.output, list):
        outputs_a = set(task_a.output)
    
    inputs_b = set()
    if isinstance(task_b.input, dict):
        inputs_b = set(task_b.input.keys())
    elif isinstance(task_b.input, list):
        inputs_b = set(task_b.input)
    
    return len(outputs_a & inputs_b) > 0


def has_resource_contention(task_a: TaskNode, task_b: TaskNode) -> bool:
    """检查是否存在资源竞争"""
    exclusive_resources = ['文件路径', '锁对象', '数据库连接', '端口号']
    
    resources_a = extract_resources(task_a)
    resources_b = extract_resources(task_b)
    
    contention = resources_a & resources_b
    return len(contention) > 0


def has_state_dependency_cross(task_a: TaskNode, task_b: TaskNode) -> bool:
    """检查是否存在交叉状态依赖"""
    state_affecting_actions = ['lock', 'start', 'create', 'open', 'init']
    
    if any(keyword in task_a.description.lower() for keyword in state_affecting_actions):
        if any(keyword in task_b.description.lower() for keyword in state_affecting_actions):
            if task_a.description.lower() != task_b.description.lower():
                return True
    
    return False
```

## 四、依赖关系判定规则

### 4.1 判定条件

满足以下所有条件，两个任务才为依赖关系：

| 规则编号 | 规则名称 | 规则描述 |
|---------|---------|---------|
| **D-1** | 输出匹配 | 任务A的输出是任务B的输入 |
| **D-2** | 数据类型兼容 | 传递的数据类型必须兼容 |
| **D-3** | 时序正确 | 任务A必须在任务B之前执行 |
| **D-4** | 必要性 | 任务B无法在任务A完成前开始 |

### 4.2 判定函数

```python
def is_dependency_relation(task_a: TaskNode, task_b: TaskNode) -> bool:
    """
    判定两个任务是否为依赖关系
    返回：(是否有依赖, 依赖类型, 依赖强度)
    """
    # 规则D-1: 输出匹配
    if not has_output_match(task_a, task_b):
        return False, None, 0.0
    
    # 规则D-2: 数据类型兼容
    if not has_type_compatibility(task_a, task_b):
        return False, None, 0.0
    
    # 规则D-3 & D-4: 时序正确且必要
    dependency_type = determine_dependency_type(task_a, task_b)
    dependency_strength = calculate_dependency_strength(task_a, task_b)
    
    return True, dependency_type, dependency_strength


def has_output_match(task_a: TaskNode, task_b: TaskNode) -> bool:
    """检查是否存在输出匹配"""
    if not task_a.output:
        return False
    
    if not task_b.input:
        return False
    
    outputs_a = extract_outputs(task_a)
    inputs_b = extract_inputs(task_b)
    
    return len(outputs_a & inputs_b) > 0


def has_type_compatibility(task_a: TaskNode, task_b: TaskNode) -> bool:
    """检查数据类型是否兼容"""
    output_types = task_a.output.get('types', {}) if isinstance(task_a.output, dict) else {}
    input_types = task_b.input.get('types', {}) if isinstance(task_b.input, dict) else {}
    
    for output_key, output_type in output_types.items():
        if output_key in input_types:
            if not is_type_compatible(output_type, input_types[output_key]):
                return False
    
    return True


def determine_dependency_type(task_a: TaskNode, task_b: TaskNode) -> str:
    """确定依赖类型"""
    if task_b.can_execute_without(task_a):
        return "soft_dependency"
    else:
        return "hard_dependency"


def calculate_dependency_strength(task_a: TaskNode, task_b: TaskNode) -> float:
    """计算依赖强度 (0.0 - 1.0)"""
    strength = 0.0
    
    # 基于输出匹配度
    outputs_a = extract_outputs(task_a)
    inputs_b = extract_inputs(task_b)
    match_ratio = len(outputs_a & inputs_b) / len(inputs_b) if inputs_b else 0.0
    strength += match_ratio * 0.4
    
    # 基于类型兼容性
    if has_type_compatibility(task_a, task_b):
        strength += 0.3
    
    # 基于数据量依赖
    if has_data_volume_dependency(task_a, task_b):
        strength += 0.3
    
    return min(strength, 1.0)


def has_data_volume_dependency(task_a: TaskNode, task_b: TaskNode) -> bool:
    """检查是否存在数据量依赖"""
    if not task_a.output or not task_b.input:
        return False
    
    if isinstance(task_a.output, dict) and 'size' in task_a.output:
        return task_a.output['size'] > 0
    
    return True
```

## 五、综合判定流程

### 5.1 判定决策树

```
开始判定任务A和任务B的关系
           │
           ▼
    ┌─────────────┐
    │ 检查依赖关系 │
    └──────┬──────┘
           │
      是 ──┴── 否
      │       │
      ▼       ▼
   返回依赖   检查串行关系
   关系       │
              │ 是 ──┐
              ▼     否
           返回串行  ▼
           关系   检查并行关系
                    │
                    │ 是 ──┐
                    ▼     │
                 返回并行  │
                 关系    返回无关系
```

### 5.2 完整判定函数

```python
class TaskRelationshipType(Enum):
    """任务关系类型枚举"""
    SERIAL = "serial"          # 串行关系
    PARALLEL = "parallel"      # 并行关系
    DEPENDENCY = "dependency"  # 依赖关系
    NONE = "none"              # 无关系


@dataclass
class RelationshipResult:
    """关系判定结果"""
    type: TaskRelationshipType
    direction: str
    strength: float
    reason: str


def determine_relationship(task_a: TaskNode, task_b: TaskNode) -> RelationshipResult:
    """
    综合判定两个任务的关系
    返回：RelationshipResult
    """
    # 优先级1: 依赖关系
    if has_output_match(task_a, task_b):
        return RelationshipResult(
            type=TaskRelationshipType.DEPENDENCY,
            direction="A → B",
            strength=calculate_dependency_strength(task_a, task_b),
            reason="任务A的输出是任务B的输入"
        )
    
    # 优先级2: 串行关系
    if is_serial_relation(task_a, task_b):
        return RelationshipResult(
            type=TaskRelationshipType.SERIAL,
            direction="A → B",
            strength=1.0,
            reason="业务逻辑或状态要求A先于B执行"
        )
    
    # 优先级3: 并行关系
    if is_parallel_relation(task_a, task_b):
        return RelationshipResult(
            type=TaskRelationshipType.PARALLEL,
            direction="A ∥ B",
            strength=1.0,
            reason="无依赖关系，可并行执行"
        )
    
    # 优先级4: 无关系
    return RelationshipResult(
        type=TaskRelationshipType.NONE,
        direction="N/A",
        strength=0.0,
        reason="任务之间无明确关系"
    )
```
