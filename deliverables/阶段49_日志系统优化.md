## 📁 交付文件

### 1. [/workspace/src/validation/logger_manager.py](file:///workspace/src/validation/logger_manager.py)

核心日志管理模块，包含以下组件：

#### 核心枚举

**`LogLevel` (日志级别)**
- `DEBUG`: 调试信息
- `INFO`: 普通信息
- `WARNING`: 警告信息
- `ERROR`: 错误信息
- `CRITICAL`: 严重错误
- `OFF`: 关闭所有日志

**`Environment` (运行环境)**
- `DEVELOPMENT`: 开发环境（默认DEBUG级别）
- `PRODUCTION`: 生产环境（默认WARNING级别）
- `TESTING`: 测试环境（默认INFO级别）

#### 核心数据类

**`PerformanceMetric`**
- 性能指标数据类
- 记录操作名称、起止时间、持续时间、内存使用等

#### 核心类

**`LoggerManager` (日志管理器)**

| 方法 | 功能描述 |
|------|----------|
| `get_logger(name)` | 获取指定名称的日志记录器 |
| `set_level(level)` | 设置全局日志级别（运行时动态调整） |
| `get_level()` | 获取当前日志级别 |
| `set_environment(env)` | 设置运行环境（自动配置日志级别） |
| `get_environment()` | 获取当前运行环境 |
| `enable_console_output(enable)` | 启用/禁用控制台输出 |
| `enable_file_output(name, filename, ...)` | 启用文件输出（支持日志轮转） |
| `disable_file_output(name)` | 禁用指定文件输出 |
| `performance_trace(name, **metadata)` | 性能追踪上下文管理器 |
| `start_performance_trace(name, **metadata)` | 开始性能追踪 |
| `end_performance_trace(trace_id)` | 结束性能追踪 |
| `get_performance_metrics()` | 获取所有性能指标 |
| `clear_performance_metrics()` | 清除所有性能指标 |

**便捷函数**
- `get_logger(name)`: 快速获取日志记录器
- `set_log_level(level)`: 快速设置日志级别
- `set_environment(env)`: 快速设置运行环境
- `performance_trace(name, **metadata)`: 快速使用性能追踪

### 4. 性能追踪

```python
from validation.logger_manager import performance_trace

# 方式1：使用上下文管理器（推荐）
with performance_trace('complex_operation', category='data_processing'):
    # 执行耗时操作
    process_large_dataset()

# 方式2：手动控制
manager = LoggerManager()
trace_id = manager.start_performance_trace('my_operation', priority='high')
try:
    # 执行操作
    do_something()
finally:
    manager.end_performance_trace(trace_id)

# 获取性能指标
metrics = manager.get_performance_metrics()
for name, metric in metrics.items():
    if metric.duration:
        print(f"{name}: {metric.duration:.4f}s")
```

### 性能监控

```python
from validation.logger_manager import LoggerManager

def monitor_performance():
    manager = LoggerManager()
    
    # 获取性能指标
    metrics = manager.get_performance_metrics()
    
    # 分析性能数据
    slow_operations = [
        (name, m.duration)
        for name, m in metrics.items()
        if m.duration and m.duration > 1.0  # 超过1秒的操作
    ]
    
    if slow_operations:
        print("发现慢操作:")
        for name, duration in sorted(slow_operations, key=lambda x: x[1], reverse=True):
            print(f"  {name}: {duration:.4f}s")
    
    # 清理已记录的指标
    manager.clear_performance_metrics()
```
