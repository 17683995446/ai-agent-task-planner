## 二、核心设计

```
DependencyCalculator（依赖计算单元）

```

### 2.2 依赖类型

```python
DependencyType:
    HARD         - 强依赖（必须完成才能执行）
    SOFT         - 软依赖（推荐但不强制）
    RECOMMENDED  - 推荐依赖
```

## 三、核心功能

### 3.1 基于输入-输出匹配计算依赖

通过分析子任务的输入规格和输出规格，自动发现数据依赖关系：

- 任务A输出某个数据 → 任务B输入相同数据 → A必须在B之前执行
- 支持类型匹配和名称匹配
- 自动设置输入来源

### 3.2 基于时间序列计算依赖

根据子任务的sequence属性，设置合理的序列依赖：

- 按时间顺序执行的任务设置SOFT依赖
- 避免不必要的强制依赖
- 支持灵活的执行顺序

### 3.3 基于内容语义计算依赖

通过分析任务名称和描述，识别语义关系：

- "准备"、"分析"、"初始化"类任务作为前置
- 后续任务设置RECOMMENDED依赖
- 提高执行成功率

### 3.4 依赖关系优化

自动优化依赖关系，避免冗余：

- 移除重复依赖
- 移除传递依赖（A→B, B→C, 则不需要A→C）
- 保持依赖图的精简和高效

## 四、使用示例

### 4.1 基本使用

```python
from topology.dependency_calculator import (
    DependencyCalculator, calculate_task_dependencies, get_dependency_graph
)
from topology.subtask_splitter import SubTaskSplitter, SplitStrategy

# 1. 拆分任务
splitter = SubTaskSplitter()
subtasks = splitter.split_task(
    "开发一个数据分析系统",
    task_id="task-datasystem",
    strategy=SplitStrategy.BY_PHASE
)

# 2. 计算依赖关系
calculator = DependencyCalculator()
subtasks_with_deps = calculator.calculate_dependencies(subtasks)

# 3. 查看结果
for task in subtasks_with_deps:
    print(f"{task.name}:")
    for dep in task.dependencies:
        print(f"  依赖于: {dep.dependency_id}")
        print(f"  原因: {dep.description}")
```

### 4.2 便捷函数使用

```python

    calculate_task_dependencies, get_dependency_graph
)

# 使用便捷函数计算依赖

# 构建依赖图
graph = get_dependency_graph(subtasks)
print(f"节点数: {graph['summary']['total_nodes']}")
print(f"边数: {graph['summary']['total_edges']}")
```

### 4.3 完整流程集成

```python
from topology.subtask_splitter import split_task_into_subtasks
from topology.dependency_calculator import calculate_task_dependencies, get_dependency_graph

# 完整流程：拆分 -> 计算依赖 -> 获取图
task_desc = "开发一个Web应用"

# 1. 拆分任务
subtasks = split_task_into_subtasks(task_desc, task_id="task-web")

# 2. 计算依赖
subtasks = calculate_task_dependencies(subtasks)

# 3. 构建依赖图
graph = get_dependency_graph(subtasks)

print("依赖图:")
for node in graph['nodes']:
    print(f"  {node['name']} (优先级: {node['priority']})")

for edge in graph['edges']:
    print(f"  {edge['from']} -> {edge['to']} ({edge['type']})")
```
