# 第27阶段交付：任务整体合法性校验接口

## 一、阶段概述

本阶段完成了基于第一性原理的AI Agent任务规划系统的任务整体合法性校验接口开发。该模块能够对完整的Task四元组进行全面的合法性检查，自动识别并报告所有不合法的字段。

**阶段工作内容**：开发任务整体合法性校验接口  
**交付物**：合法性校验函数  
**验收标准**：缺字段任务自动判定非法

## 二、合法性校验器设计

### 2.1 核心功能

合法性校验器的主要功能包括：
1. **Task基本信息校验**：校验任务ID、状态等基础信息
2. **Target字段校验**：校验目标描述、可衡量标准、优先级等
3. **Condition字段校验**：校验前置条件列表、类型、规则等
4. **Boundary字段校验**：校验范围边界、资源约束、质量约束等
5. **EndRule字段校验**：校验成功条件、失败条件、检查规则等
6. **完整错误报告**：返回所有错误的详细列表

### 2.2 模块架构

```
TaskValidator（任务合法性校验器）
├── validate()：主校验入口，返回(是否合法, 错误列表)
├── validate_or_raise()：校验入口，不合法时抛出异常
├── _validate_task_basic()：校验Task基本信息
├── _validate_target()：校验Target字段
├── _validate_condition()：校验Condition字段
├── _validate_boundary()：校验Boundary字段
└── _validate_end_rule()：校验EndRule字段
```

## 三、校验规则详细说明

### 3.1 Task基本信息校验

| 校验项 | 规则 | 错误信息 |
|-------|------|---------|
| 任务ID | 不能为空 | "任务ID不能为空" |
| 任务状态 | 必须是有效枚举值 | "任务状态无效" |

### 3.2 Target字段校验

| 校验项 | 规则 | 错误信息 |
|-------|------|---------|
| ID | 不能为空 | "Target的ID不能为空" |
| 描述 | 不能为空，最大500字符 | "Target的描述不能为空" / "Target的描述过长" |
| 可衡量标准 | 至少一个 | "Target至少需要一个可衡量标准" |
| 优先级 | 必须在1-10之间 | "Target的优先级必须在1-10之间" |
| 标准类型 | 必须为boolean/numeric/qualitative | "可衡量标准的类型无效" |
| 数值阈值 | numeric类型必须设置阈值 | "可衡量标准为数值类型但未设置阈值" |

### 3.3 Condition字段校验

| 校验项 | 规则 | 错误信息 |
|-------|------|---------|
| 逻辑运算符 | 必须为AND或OR | "Condition的logical_operator必须为AND或OR" |
| 条件列表 | 至少一个条件或明确标注无前置 | "Condition至少需要一个条件或明确标注无前置条件" |
| 条件项ID | 不能为空 | "前置条件的ID不能为空" |
| 条件类型 | 必须为existence/value/state | "前置条件的类型无效" |
| 检查规则 | 必须设置 | "前置条件必须设置check_rule" |

### 3.4 Boundary字段校验

| 校验项 | 规则 | 错误信息 |
|-------|------|---------|
| Scope对象 | 不能为空 | "Boundary的scope不能为空" |
| 包含列表 | 必须是列表 | "Boundary.scope.inclusions必须是列表" |
| 排除列表 | 必须是列表 | "Boundary.scope.exclusions必须是列表" |
| 最大时间 | 必须>0 | "max_time_seconds必须大于0" |
| 最大成本 | 不能<0 | "max_cost不能为负数" |
| 最大迭代 | 必须>0 | "max_iterations必须大于0" |
| 准确率 | 必须在0-1之间 | "min_accuracy必须在0-1之间" |
| 错误率 | 必须在0-1之间 | "max_error_rate必须在0-1之间" |

### 3.5 EndRule字段校验

| 校验项 | 规则 | 错误信息 |
|-------|------|---------|
| 成功条件 | 至少一个 | "EndRule至少需要一个成功条件" |
| 条件ID | 不能为空 | "成功/失败条件的ID不能为空" |
| 条件描述 | 不能为空 | "成功/失败条件的描述不能为空" |
| 检查规则 | 必须设置 | "成功/失败条件必须设置check_rule" |
| 失败条件 | 建议至少一个 | "EndRule建议至少有一个失败条件" |
| 优先级 | 必须>=1 | "失败条件的优先级必须>=1" |

## 四、使用示例

### 4.1 基本使用

```python
from task_modeling.task_validator import validate_task

# 创建或获取Task对象
task = create_your_task()

# 校验任务合法性
is_valid, errors = validate_task(task)

if is_valid:
    print("任务合法，可以进入规划阶段")
else:
    print(f"任务不合法，共{len(errors)}个错误:")
    for err in errors:
        print(f"  - {err}")
```

### 4.2 异常抛出模式

```python
from task_modeling.task_validator import validate_task_or_raise, TaskValidationError

try:
    task = create_your_task()
    validate_task_or_raise(task)
    print("任务合法！")
except TaskValidationError as e:
    print(f"任务校验失败:")
    for err in e.errors:
        print(f"  - {err}")
```

### 4.3 完整校验流程

```python
from task_modeling.task_validator import TaskValidator

validator = TaskValidator()

# 创建Task
task = create_your_task()

# 方式1：获取详细错误列表
is_valid, errors = validator.validate(task)
if not is_valid:
    print("任务不合法:")
    for error in errors:
        print(f"  - {error}")

# 方式2：直接抛出异常
try:
    validator.validate_or_raise(task)
    print("任务合法！")
except TaskValidationError as e:
    print(f"任务不合法，共{len(e.errors)}个错误")
```
