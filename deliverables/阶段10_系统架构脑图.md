## 二、第一层：任务归一建模层详细展开

```
任务归一建模层
│
├─ 输入
│  └─ 用户原始自然语言需求
│
├─ 处理模块
│  ├─ Target 归一化模块
│  │  ├─ 目标提取
│  │  ├─ 多歧义排除
│  │  ├─ 可衡量标准定义
│  │  └─ 优先级设置
│  │
│  ├─ Condition 识别模块
│  │  ├─ 前置条件自动识别
│  │  ├─ 条件可判定性检查
│  │  └─ 条件依赖关系分析
│  │
│  ├─ Boundary 约束模块
│  │  ├─ 范围边界定义 (包含/排除)
│  │  ├─ 资源约束设置 (时间/成本/迭代)
│  │  └─ 质量约束定义 (准确率/错误率)
│  │
│  └─ EndRule 终止解析器
│     ├─ 成功条件定义
│     ├─ 失败条件定义
│     └─ 判定逻辑表达式化
│
├─ 输出
│  └─ 标准四元组 Task
│     ├─ target: Target
│     ├─ condition: Condition
│     ├─ boundary: Boundary
│     └─ endRule: EndRule
│
└─ 合法性校验
   └─ 四元组完整性检查
```

│  │  └─ 无关任务过滤
│  │
│  ├─ 依赖关系自动计算
│  │  ├─ 输入输出分析
│  │  ├─ 串行依赖识别
│  │  └─ 并行独立识别
│  │
│  ├─ DAG图生成器
│  │  ├─ 节点创建
│  │  ├─ 边创建
│  │  └─ 拓扑排序
│  │
│  ├─ 拓扑纠错模块
│  │  ├─ 循环依赖检测
│  │  ├─ 悬空节点检测
│  │  └─ 孤立节点检测
│  │
│  └─ 调度标记逻辑
│     ├─ 串行节点标记
│     └─ 并行节点标记
│
├─ 输出
│  └─ 合法DAG有向无环图

## 六、数据流转完整链路图

```
[用户原始需求]
       │
       ▼
┌───────────────────┐     校验不通过
│ 任务归一建模层    ├──────────────→ [拒绝执行]
└─────────┬─────────┘     并说明原因
          │
          │ 输出: 标准四元组 Task
          ▼
┌───────────────────┐     拓扑不合法
│ 拓扑依赖拆解层    ├──────────────→ [返回第二层重新拓扑]
└─────────┬─────────┘
          │
          │ 输出: DAG有向无环图
          ▼
┌───────────────────┐     原子化不通过
│ 原子动作收敛层    ├──────────────→ [返回第三层继续细化]
└─────────┬─────────┘
          │
          │ 输出: 原子动作队列
          ▼
┌───────────────────┐
│ 分段校验收敛层    │
│  ┌─────────────┐ │
│  │ 预校验阶段  ├─┬───不通过──→ [返回第一层/第二层]
│  └──────┬──────┘ │
│         │        │
│         ▼        │
│  ┌─────────────┐ │
│  │  执行阶段   │ │
│  └──────┬──────┘ │
│         │        │
│         ▼        │
│  ┌─────────────┐ │
│  │执行后校验阶段├─┬───不通过──→ [熔断/回滚/局部重规划]
│  └──────┬──────┘ │
│         │        │
│         ▼        │
│  ┌─────────────┐ │
│  │ 检查终止?   ├─┬───否──→ (返回预校验/执行阶段)
│  └──────┬──────┘ │
│         │        │
│         ▼        │
│  ┌─────────────┐ │
│  │  终止阶段   │ │
│  └─────────────┘ │
└─────────┬─────────┘
          │
          ▼
     [收敛结果]
```
