## 📁 交付文件

### 1. `/workspace/src/validation/action_post_validator.py`

核心实现文件，包含以下组件：

#### 核心枚举

**`OutputValidationStatus` (输出验证状态)**
- `VALID`: 有效
- `INVALID`: 无效
- `PARTIAL`: 部分有效
- `EMPTY`: 空输出
- `ERROR`: 错误

**`ErrorSeverity` (错误严重程度)**
- `LOW`: 轻微
- `MEDIUM`: 中等
- `HIGH`: 高
- `CRITICAL`: 严重

#### 核心数据类

**`ActionOutput`**
- 动作输出数据类
- 包含成功状态、数据、错误信息、执行时间

**`OutputValidationRule`**
- 输出验证规则
- 包含验证函数和严重程度

**`PostActionValidationReport`**
- 后校验报告
- 包含验证状态、结果列表、执行时间

#### 核心类

**`ActionPostValidator` (动作后校验器)**

| 方法 | 功能描述 |
|------|----------|
| `validate_action_output()` | 验证动作输出 |
| `_register_default_rules()` | 注册默认验证规则 |
| `_update_stats()` | 更新统计信息 |
| `get_statistics()` | 获取统计信息 |
| `get_validation_history()` | 获取验证历史 |
| `get_failed_validations()` | 获取失败的验证 |

**便捷函数**
- `quick_validate_output()`: 快速验证动作输出

```python
from action_post_validator import ActionPostValidator

```

### 2. 自定义验证规则

```python
from action_post_validator import (
    ActionPostValidator,
    ActionOutput,
    OutputValidationRule,
    ErrorSeverity
)

validator = ActionPostValidator()

# 添加自定义规则
validator.add_rule(OutputValidationRule(
    rule_id="custom_rule",
    name="自定义验证",
    validator=lambda output: len(str(output.data)) < 10000,
    severity=ErrorSeverity.MEDIUM,
    description="检查输出数据大小"
))
```

### 3. 输出验证

```python
# 创建动作输出
output = ActionOutput(
    action_id="action_001",
    success=True,
    data={"result": "success"},
    execution_time=0.5

report = validator.validate_action_output("action_001", output)
```

## 💡 使用示例

### 基本使用

```python
from src.validation.action_post_validator import (
    ActionPostValidator,
    ActionOutput,
    quick_validate_output
)

# 1. 创建校验器
validator = ActionPostValidator()

# 2. 创建动作输出
output = ActionOutput(
    action_id="data_processing",
    success=True,
    data={"records": 1000, "status": "completed"},
    error=None,
    execution_time=2.5
)

# 3. 验证输出
report = validator.validate_action_output("data_processing", output)

# 4. 检查结果
if report.is_valid():
    print("✅ 动作输出有效")
else:
    print(f"❌ 验证失败: {report.validation_status.value}")

# 5. 获取统计
stats = validator.get_statistics()
print(f"总验证数: {stats['total_validations']}")
print(f"成功率: {stats['success_rate']:.1%}")
```

### 快速验证

```python
# 使用便捷函数快速验证
report = quick_validate_output(
```
