# 第38阶段交付：链路绑定逻辑

## 一、阶段概述

本阶段完成了第二层拓扑依赖拆解层的第八个核心组件：链路绑定逻辑。该模块能够自动验证子任务之间的输入输出绑定关系，确保后节点输入正确对应前节点输出，发现并报告绑定问题。

**阶段工作内容**：实现节点输入输出前后绑定校验  
**交付物**：链路绑定逻辑  
**验收标准**：后节点输入 = 前节点输出

## 二、核心设计

### 2.1 链路验证数据结构

```
LinkValidatedTopology（链路验证后拓扑）
├── original_topology: TopologyStructure - 原始拓扑
├── bound_links: List[BoundLink] - 绑定链路
├── issues: List[BindIssue] - 发现的问题
├── is_valid: bool - 是否有效
├── valid_count: int - 有效绑定数
└── issue_count: int - 问题数

BoundLink（绑定链路）
├── from_node, from_output - 源节点输出
├── to_node, to_input - 目标节点输入
├── bind_type: str - 绑定类型
└── is_valid: bool - 是否有效

BindIssue（绑定问题）
├── node_id, name - 节点信息
├── issue_type: BindStatus - 问题类型
├── description: str - 描述
├── related_node: Optional[str] - 相关节点
└── related_spec: Optional[str] - 相关规格

BindStatus（绑定状态）
├── VALID - 有效
├── MISSING_OUTPUT - 缺少输出
├── MISSING_INPUT - 缺少输入
├── TYPE_MISMATCH - 类型不匹配
├── UNNECESSARY_OUTPUT - 不必要的输出
└── NO_CONNECTION - 无连接
```

### 2.2 组件架构

```
LinkBinder（链路绑定器）
├── validate_links() - 主验证入口
├── _build_output_map() - 构建输出映射
├── _find_task() - 查找任务
└── validated_to_dict() - 转换为字典
```

## 三、核心功能

### 3.1 显式来源检查

**检查策略**：
- 检查input.source字段指定的来源
- 确认来源节点存在对应输出
- 验证类型匹配

**检查标准**：
- 来源节点必须存在
- 来源节点必须有同名输出
- 类型应该兼容

### 3.2 依赖关系连接检查

**检查策略**：
- 对每个依赖关系，检查是否有输出输入连接
- 源节点输出与目标节点输入匹配
- 自动识别隐含的绑定关系

**检查标准**：
- 有依赖的节点应该有输出输入连接
- 名称和类型匹配的应该被识别

### 3.3 未使用输出检查

**检查策略**：
- 识别没有被任何其他节点使用的输出
- 标记为不必要的输出

**检查标准**：
- 输出不在任何绑定链路中
- 不是结束节点的输出

### 3.4 完整验证流程

1. 生成拓扑结构
2. 检查显式来源的输入
3. 检查依赖关系的连接
4. 检查未使用的输出
5. 生成验证报告

## 四、使用示例

### 4.1 基本使用

```python
from topology.link_binder import LinkBinder, validate_task_links, validate_and_get_dict
from topology.subtask_splitter import SubTaskSplitter, SplitStrategy

# 1. 拆分任务
splitter = SubTaskSplitter()
subtasks = splitter.split_task(
    "开发一个Web应用系统",
    task_id="task-webapp",
    strategy=SplitStrategy.BY_PHASE
)

# 2. 验证链路绑定
binder = LinkBinder()
validated = binder.validate_links(subtasks)

# 3. 查看结果
print(f"验证通过: {validated.is_valid}")
print(f"有效绑定: {validated.valid_count}")
print(f"问题数量: {validated.issue_count}")

print("\n绑定链路:")
for i, link in enumerate(validated.bound_links, 1):
    print(f"  {i}. [{link.from_node}] → {link.from_output}")
    print(f"     ↓")
    print(f"     [{link.to_node}] ← {link.to_input}")

if validated.issues:
    print("\n发现的问题:")
    for i, issue in enumerate(validated.issues, 1):
        print(f"  {i}. [{issue.node_id}] {issue.name}")
        print(f"     问题: {issue.issue_type.value} - {issue.description}")
```

### 4.2 便捷函数使用

### 4.3 完整流程集成

```python
from topology.subtask_splitter import split_task_into_subtasks
from topology.link_binder import validate_and_get_dict

# 完整流程：拆分 → 验证链路
task_desc = "开发一个复杂系统"

# 1. 拆分任务
subtasks = split_task_into_subtasks(task_desc, task_id="task-complex")

# 2. 验证链路
result_dict = validate_and_get_dict(subtasks)

# 3. 检查结果
if result_dict['is_valid']:
    print("✅ 链路验证通过")
    print(f"发现 {result_dict['valid_count']} 个有效绑定")
    
    print("\n绑定链路列表:")
    for i, link in enumerate(result_dict['bound_links'], 1):
        print(f"  {i}. [{link['from_node']}] → {link['from_output']}")
        print(f"     ↓")
        print(f"     [{link['to_node']}] ← {link['to_input']}")
else:
    print("❌ 链路验证发现问题")
    print(f"发现 {result_dict['issue_count']} 个问题")
    
    print("\n问题详情:")
    for i, issue in enumerate(result_dict['issues'], 1):
        print(f"  {i}. [{issue['node_id']}] {issue['name']}")
        print(f"     问题: {issue['issue_type']} - {issue['description']}")
```
