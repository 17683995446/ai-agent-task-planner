## 二、核心设计

### 2.1 数据结构设计

```
AtomicAction (原子动作)
├── action_id: str              # 动作唯一标识
├── name: str                    # 动作名称
├── description: str               # 动作描述
├── action_type: AtomicActionType  # 动作类型
├── inputs: List[ActionInput]     # 输入定义
├── outputs: List[ActionOutput]  # 输出定义
├── dependencies: List[str]          # 依赖的前置动作ID
├── constraints: ActionConstraint   # 约束条件
├── atomic_conditions: Set[AtomicCondition] # 满足的原子条件
├── status: AtomicActionStatus   # 当前状态
├── priority: int                 # 优先级 (1-10)
├── metadata: Dict                # 扩展元数据
├── created_at: float           # 创建时间戳
└── updated_at: float             # 更新时间戳

ActionInput (输入定义)
├── name: str
├── type: str
├── required: bool
├── description: str
├── default: Any
└── constraints: Dict

ActionOutput (输出定义)
├── name: str
├── type: str
├── description: str
└── constraints: Dict

ActionConstraint (约束条件)
├── max_execution_time: float
├── required_permissions: List[str]
├── resource_limits: Dict
├── retry_policy: Dict
└── timeout_policy: Dict

AtomicCondition (原子判定条件)
├── SINGLE_RESPONSIBILITY  # 单一职责原则
├── SIDE_EFFECT_FREE        # 无副作用原则
└── IDEMPOTENT               # 幂等性原则

AtomicActionType (动作类型)
├── DATA_READ, DATA_WRITE, TRANSFORM
├── API_CALL, FILE_IO, NETWORK
├── COMPUTATION, VALIDATION, DECISION
└── CUSTOM

AtomicActionStatus (动作状态)
├── PENDING, READY, RUNNING
├── COMPLETED, FAILED, SKIPPED

AtomicActionQueue (原子动作队列)
├── queue_id: str
├── name: str
├── actions: List[AtomicAction]
└── status: str
└── metadata: Dict
```

### 2.2 原子动作三原则

#### 1. 单一职责原则 (Single Responsibility)
- **定义**：一个原子动作只做一件事，且只有一个导致其变更的原因
- **验证标准**：
  - 输入输出明确
  - 职责边界清晰
  - 可独立测试

#### 2. 无副作用原则 (Side Effect Free)
- **定义**：原子动作不改变外部状态，或明确声明副作用
- **验证标准**：
  - 纯函数式设计
  - 输入决定输出
  - 无隐藏状态改变

#### 3. 幂等性原则 (Idempotent)
- **定义**：多次执行产生同样结果一致
- **验证标准**：
  - f(f(x)) = f(x)
  - 多次执行不影响最终状态
  - 可安全重试

## 四、使用示例

### 4.1 创建原子动作

```python
from atomic_action_struct import (
    AtomicAction, AtomicActionType, AtomicCondition,
    AtomicActionStatus, create_atomic_action
)

# 创建一个读取配置的原子动作
read_config = create_atomic_action(
    action_id="read_config",
    name="读取配置",
    description="从文件系统读取配置文件",
    action_type=AtomicActionType.FILE_IO,
    priority=3
)

# 添加输入定义
read_config.add_input(
    name="file_path",
    type="string",
    required=True,
    description="配置文件路径"
)

read_config.add_input(
    name="encoding",
    type="string",
    required=False,
    default="utf-8",
    description="文件编码"
)

# 添加输出定义
read_config.add_output(
    name="config_data",
    type="dict",
    description="配置数据字典"
)

# 标记原子条件
read_config.add_atomic_condition(
    AtomicCondition.SINGLE_RESPONSIBILITY
)
read_config.add_atomic_condition(
    AtomicCondition.SIDE_EFFECT_FREE
)

# 验证原子条件
conditions = read_config.validate_atomic_conditions()
# {'single_responsibility': True,
#  'side_effect_free': True,
#  'idempotent': False}
```

### 4.2 创建原子动作队列

```python
from atomic_action_struct import AtomicActionQueue

queue = AtomicActionQueue(
    queue_id="data_pipeline",
    name="数据处理流水线"
)

# 创建动作1
read_data = create_atomic_action(
    action_id="read_data",
    name="读取数据",
    action_type=AtomicActionType.DATA_READ
)
read_data.add_input("source", "string", required=True)
read_data.add_output("raw_data", "list")

# 创建动作2
clean_data = create_atomic_action(
    action_id="clean_data",
    name="清洗数据",
    action_type=AtomicActionType.TRANSFORM
)
clean_data.add_input("raw_data", "list", required=True)
clean_data.add_dependency("read_data")
clean_data.add_output("clean_data", "list")

# 批量添加
queue.add_actions([read_data, clean_data])

# 获取待执行动作
pending = queue.get_pending_actions()
```
