## 📁 交付文件

### 1. [src/validation/performance_monitor.py](file:///workspace/src/validation/performance_monitor.py)

核心性能监控模块，包含以下组件：

#### 核心枚举

**AlertLevel (告警级别)**
- INFO, WARNING, ERROR, CRITICAL

**AnomalyType (异常类型)**
- SLOW, ERROR_RATE, THROUGHPUT, RESOURCE

#### 核心数据类

**PerformanceMetric**
- 性能指标记录

**ThresholdRule**
- 阈值规则定义

**PerformanceStats**
- 性能统计结果（Min/Max/Mean/Median/StdDev/P95/P99）

**Alert**
- 告警信息

#### 核心类

**PerformanceMonitor (性能监控器)**

| 方法 | 功能描述 |
|------|----------|
| `record(name, value, ...)` | 记录性能指标 |
| `get_stats(name)` | 获取统计数据 |
| `get_history(name, limit)` | 获取历史数据 |
| `add_threshold_rule(rule)` | 添加阈值规则 |
| `add_alert_listener(listener)` | 添加告警监听器 |
| `get_alerts(level, limit)` | 获取告警记录 |
| `detect_anomalies(name, ...)` | 检测异常 |
| `get_trend(name, window)` | 分析趋势 |

**TimedOperation (计时操作)**
- 上下文管理器，自动记录操作耗时

## 💡 使用示例

### 场景1: 验证系统性能监控

```python
from validation.performance_monitor import (
    create_performance_monitor,
    ThresholdRule,
    AlertLevel,
    TimedOperation
)

# 创建监控器
monitor = create_performance_monitor()

# 添加告警规则
monitor.add_threshold_rule(ThresholdRule(
    name="validation_latency",
    threshold=500,  # 500ms
    alert_level=AlertLevel.WARNING,
    operator=">"
))

monitor.add_threshold_rule(ThresholdRule(
    name="error_rate",
    threshold=0.05,  # 5%
    alert_level=AlertLevel.ERROR,
    operator=">"
))

# 监控验证操作
def validate_with_monitoring(task_id):
    with TimedOperation(monitor, "validation_latency", {"task_id": task_id}):
        try:
            result = perform_validation(task_id)
            monitor.record("error_rate", 0.0)
            return result
        except Exception as e:
            monitor.record("error_rate", 1.0)
            raise

# 定期检查健康状况
def check_system_health():
    stats = monitor.get_stats("validation_latency")
    if stats and stats.p95 > 500:
        print("⚠️ P95延迟超过阈值!")
    
    anomalies = monitor.detect_anomalies("validation_latency")
    if anomalies:
        print(f"🔍 检测到 {len(anomalies)} 个异常!")
    
    trend = monitor.get_trend("validation_latency")
    print(f"📈 趋势: {trend['trend']}")
```

### 场景2: 性能告警集成

```python
from validation.performance_monitor import Alert

# 告警处理器
def handle_performance_alert(alert: Alert):
    # 根据级别处理
    if alert.level == AlertLevel.CRITICAL:
        send_pager_duty(alert)
    elif alert.level == AlertLevel.ERROR:
        send_slack_alert(alert)
    elif alert.level == AlertLevel.WARNING:
        log_to_dashboard(alert)
    
    print(f"处理告警: {alert.level.name} - {alert.message}")

# 注册处理器
monitor.add_alert_listener(handle_performance_alert)

# 导出性能报告
def export_performance_report():
    report = {
        "timestamp": time.time(),
        "metrics": {},
        "alerts": []
    }
    
    for name, stats in monitor.get_stats().items():
        report["metrics"][name] = {
            "count": stats.count,
            "mean": stats.mean,
            "p95": stats.p95,
            "p99": stats.p99
        }
    
    for alert in monitor.get_alerts(limit=100):
        report["alerts"].append(alert.to_dict())
    
    return report
```
