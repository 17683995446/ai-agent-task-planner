#### 优化3：限制递归深度

```python
# 在 topology_corrector.py 中优化
def _has_cycle(self, adj: Dict[str, List[str]], node_id: str, 
               visited: Set[str], rec_stack: Set[str], depth: int = 0) -> bool:
    MAX_DEPTH = 1000  # 添加深度限制
    
    if depth > MAX_DEPTH:
        return False  # 超过深度限制，视为无循环
    
    visited.add(node_id)
    rec_stack.add(node_id)
    
    for neighbor in adj.get(node_id, []):
        if neighbor not in visited:
            if self._has_cycle(adj, neighbor, visited, rec_stack, depth + 1):
                return True
        elif neighbor in rec_stack:
            return True
    
    rec_stack.remove(node_id)
    return False
```

**预期收益**：防止无限递归，提高系统稳定性
