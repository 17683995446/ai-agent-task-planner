## 一、命名规范

### 1.1 目录和文件命名

#### 目录命名规范
- 使用小写字母和下划线
- 有明确语义，避免缩写
- 示例：`task_modeling`、`topology`、`atomic_actions`、`validation`

#### 文件命名规范
- 模块文件使用小写字母和下划线
- 示例：`task_struct.py`、`dag_generator.py`
- 测试文件以`test_`开头
- 示例：`test_task_struct.py`
- 配置文件使用`.yaml`或`.env`格式
- 示例：`config.yaml`、`.env.example`

### 1.2 代码命名规范

#### 类命名
- 使用大驼峰命名法（CapWords）
- 首字母大写，单词间不使用下划线
- 示例：`TaskParser`、`DAGGenerator`、`AtomicAction`

#### 函数和方法命名
- 使用小写下划线命名法（snake_case）
- 动词开头，表示功能
- 示例：`parse_task()`、`generate_dag()`、`validate_action()`

#### 变量和常量命名
- 普通变量使用小写下划线命名法
- 示例：`target_name`、`condition_list`
- 常量使用大写字母和下划线
- 示例：`MAX_RETRY_COUNT`、`DEFAULT_TIMEOUT`

#### 私有属性和方法
- 使用单下划线前缀表示内部使用
- 示例：`_internal_state`、`_helper_function()`

## 二、结构体规范

### 2.1 数据类（Dataclass）规范

#### 通用要求
- 使用`@dataclass`装饰器
- 使用类型注解
- 包含文档字符串（docstring）
- 包含必要的验证逻辑

#### 示例：Task四元组结构
```python
from dataclasses import dataclass, field
from typing import List, Dict, Any, Optional
from enum import Enum

class TaskStatus(Enum):
    PENDING = "pending"
    IN_PROGRESS = "in_progress"
    COMPLETED = "completed"
    FAILED = "failed"

@dataclass
class Target:
    description: str
    measurable_criteria: List[str]
    priority: int = 1
    metadata: Dict[str, Any] = field(default_factory=dict)
    
    def is_valid(self) -> bool:
        return bool(self.description) and len(self.measurable_criteria) > 0

@dataclass
class Condition:
    conditions: List[str]
    check_functions: Dict[str, Any] = field(default_factory=dict)

@dataclass
class Boundary:
    scope: str
    resource_limits: Dict[str, Any]
    quality_requirements: Optional[Dict[str, Any]] = None

@dataclass
class EndRule:
    success_conditions: List[str]
    failure_conditions: List[str]
    evaluation_logic: str

@dataclass
class Task:
    id: str
    target: Target
    condition: Condition
    boundary: Boundary
    end_rule: EndRule
    status: TaskStatus = TaskStatus.PENDING
    created_at: float = field(default_factory=lambda: __import__('time').time())
    metadata: Dict[str, Any] = field(default_factory=dict)
    
    def __post_init__(self):
        if not self.target.is_valid():
            raise ValueError("Invalid target configuration")
```

### 2.2 节点和DAG结构体规范

#### 节点结构

```python
class Node:

    status: str = "pending"

```

#### DAG结构
```python
@dataclass
class DAG:
    nodes: List[Node]
    edges: List[Tuple[str, str]]  # (from_node_id, to_node_id)
    root_nodes: List[str]
    leaf_nodes: List[str]
    
    def get_node_by_id(self, node_id: str) -> Optional[Node]:
        for node in self.nodes:
            if node.id == node_id:
                return node
        return None
```

#### LLM适配器抽象基类

```python
from abc import ABC, abstractmethod
from typing import List, Dict, Any

class LLMAdapter(ABC):

    def generate(self, prompt: str, config: Dict[str, Any]) -> str:
        pass
    
    @abstractmethod

        pass
    
    @abstractmethod
```

### 3.2 接口设计原则

#### 统一的输入输出格式
- 接口输入必须包含明确的类型注解
- 接口输出必须是结构化数据（dict或dataclass）
- 错误输出必须包含统一的错误格式

## 四、日志规范

### 4.1 日志级别

| 级别 | 用途 | 示例 |
|-------|------|------|
| DEBUG | 详细的调试信息 | 变量值、函数输入输出 |
| INFO | 正常的程序运行信息 | 任务开始、完成、状态变更 |
| WARNING | 可能的问题，不影响程序运行 | 非关键参数缺失、使用默认值 |
| ERROR | 错误发生，影响功能正常执行 | 函数执行失败、验证失败 |
| CRITICAL | 严重错误，程序可能崩溃 | 系统资源耗尽、无法恢复的错误 |

### 4.2 日志格式规范

#### 标准日志格式
```python
[时间] [级别] [模块名] [函数名] [行号] - 消息内容
```

#### 时间格式
使用 ISO 8601 格式：`YYYY-MM-DD HH:MM:SS.sss`

#### 日志记录器配置
```python
import logging
import sys
from datetime import datetime

def setup_logger(name: str = "planning_system", level: int = logging.INFO) -> logging.Logger:
    logger = logging.getLogger(name)
    logger.setLevel(level)
    
    formatter = logging.Formatter(
        '[%(asctime)s] [%(levelname)s] [%(module)s] [%(funcName)s] [%(lineno)d] - %(message)s',
        datefmt='%Y-%m-%d %H:%M:%S.%f'[:-3]
    )
    
    # 控制台处理器
    console_handler = logging.StreamHandler(sys.stdout)
    console_handler.setFormatter(formatter)
    
    # 文件处理器
    log_file = f"logs/planning_{datetime.now().strftime('%Y%m%d')}.log"
    file_handler = logging.FileHandler(log_file, encoding='utf-8')
    file_handler.setFormatter(formatter)
    
    logger.addHandler(console_handler)
    logger.addHandler(file_handler)
    
    return logger
```
