```python
SplitStrategy:
    BY_CRITERION  - 按可衡量标准拆分

    BY_PHASE      - 按执行阶段拆分（默认）

```


## 三、核心功能

### 3.1 按执行阶段拆分（BY_PHASE）

最通用的拆分策略，适用于大多数任务：

1. **任务分析** - 分析任务要求，理解目标与约束
2. **准备规划** - 准备执行环境，制定详细执行计划
3. **核心执行** - 执行核心任务逻辑，处理主要工作
4. **验证优化** - 验证执行结果，进行必要优化
5. **交付收尾** - 整理结果，完成最终交付

### 3.2 按可衡量标准拆分（BY_CRITERION）

根据任务的衡量标准进行拆分：

1. **标准分析** - 分析各项衡量标准，确定优先级
2. **目标达成** - 执行工作以达成各项衡量标准
3. **标准验证** - 验证所有标准是否已满足

### 3.3 按前置条件拆分（BY_CONDITION）

根据前置条件进行拆分：

1. **条件准备** - 检查并准备所有前置条件
2. **核心执行** - 在条件满足的情况下执行任务

### 3.4 按可并行部分拆分（BY_PARALLEL）

识别可并行执行的部分：

1. **公共准备** - 为所有并行任务做准备
2. **并行任务A** - 执行可并行的第一部分工作
3. **并行任务B** - 执行可并行的第二部分工作
4. **结果合并** - 合并所有并行任务的结果

## 四、使用示例

### 4.1 基本使用

```python
from topology.subtask_splitter import SubTaskSplitter, SplitStrategy

# 创建拆分引擎
splitter = SubTaskSplitter()

# 拆分任务
task_description = "开发一个Web应用，包含用户管理和数据分析功能"
subtasks = splitter.split_task(
    task_description,
    task_id="task-webapp",
    strategy=SplitStrategy.BY_PHASE
)

# 查看结果
for i, subtask in enumerate(subtasks, 1):
    print(f"{i}. {subtask.name}")
    print(f"   ID: {subtask.node_id}")
    print(f"   输入: {len(subtask.inputs)}")
    print(f"   输出: {len(subtask.outputs)}")
    print(f"   依赖: {len(subtask.dependencies)}")
```

### 4.2 便捷函数使用

```python
from topology.subtask_splitter import split_task_into_subtasks

# 使用便捷函数拆分
subtasks = split_task_into_subtasks(
    task_description="生成年度报告",
    task_id="task-report",
    strategy="by_phase"  # "by_phase" | "by_criterion" | "by_condition" | "by_parallel"
)
```

### 4.3 多种策略选择

```python
# 策略1：按阶段（通用）
subtasks1 = splitter.split_task(task_desc, strategy=SplitStrategy.BY_PHASE)

# 策略2：按标准（质量导向）
subtasks2 = splitter.split_task(task_desc, strategy=SplitStrategy.BY_CRITERION)

# 策略3：按条件（约束导向）
subtasks3 = splitter.split_task(task_desc, strategy=SplitStrategy.BY_CONDITION)

# 策略4：按并行（性能导向）
subtasks4 = splitter.split_task(task_desc, strategy=SplitStrategy.BY_PARALLEL)
```
