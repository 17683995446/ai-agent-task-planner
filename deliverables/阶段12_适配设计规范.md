## 一、适配原则总览

### 1.1 核心目标

确保系统架构不绑定任何特定 LLM（大型语言模型）和任何特定 Agent 框架，实现真正的模型无关性和框架无关性。

### 1.2 适配策略

| 策略 | 描述 | 实现方式 |
|-----|------|---------|
| **接口抽象** | 定义标准接口，不依赖具体实现 | 使用抽象基类和接口定义 |
| **依赖注入** | 将外部依赖通过配置注入 | 解耦核心逻辑与具体实现 |
| **配置驱动** | 通过配置文件选择适配器 | 不硬编码具体实现 |
| **最小依赖原则** | 核心层不引入不必要的依赖 | 保持架构纯净 |

## 二、模型无关性设计

### 2.1 适配目标

系统需要支持的主流 LLM 类型：

| 模型类型 | 代表模型 | 适配要求 |
|---------|---------|---------|
| OpenAI 系列 | GPT-4、GPT-3.5 | 通过 OpenAI 适配器 |
| Claude 系列 | Claude 3、Claude 2 | 通过 Anthropic 适配器 |
| 开源模型 | Llama、Qwen、Mistral | 通过 OpenAI 兼容接口 |
| 本地模型 | Ollama、LLaMA.cpp | 通过本地部署接口 |
| 其他模型 | 任意支持标准接口的模型 | 通过通用适配器 |

### 2.2 LLM 调用接口抽象

```python
class LLMAdapter(ABC):
    """LLM 适配器抽象基类"""
    
    @abstractmethod
    def generate(self, prompt: str, config: GenerationConfig) -> GenerationResult:
        """
        生成文本
        参数：
            prompt: 输入提示词
            config: 生成配置
        返回：
            GenerationResult: 生成结果
        """
        pass
    
    @abstractmethod
    def chat(self, messages: List[Message], config: ChatConfig) -> ChatResult:
        """
        对话生成
        参数：
            messages: 消息列表
            config: 对话配置
        返回：
            ChatResult: 对话结果
        """
        pass
    
    @abstractmethod
    def get_model_info(self) -> ModelInfo:
        """
        获取模型信息
        返回：
            ModelInfo: 模型信息
        """
        pass
```

### 2.3 模型适配器实现示例

#### OpenAI 适配器

```python
class OpenAIAdapter(LLMAdapter):
    """OpenAI 模型适配器"""
    
    def __init__(self, api_key: str, model: str = "gpt-4"):
        self.client = OpenAI(api_key=api_key)
        self.model = model
    
    def generate(self, prompt: str, config: GenerationConfig) -> GenerationResult:
        response = self.client.completions.create(
            model=self.model,
            prompt=prompt,
            temperature=config.temperature,
            max_tokens=config.max_tokens
        )
        return GenerationResult(
            text=response.choices[0].text,
            usage=Usage(
                prompt_tokens=response.usage.prompt_tokens,
                completion_tokens=response.usage.completion_tokens
            )
        )
    
    def chat(self, messages: List[Message], config: ChatConfig) -> ChatResult:
        response = self.client.chat.completions.create(
            model=self.model,
            messages=[m.to_dict() for m in messages],
            temperature=config.temperature,
            max_tokens=config.max_tokens
        )
        return ChatResult(
            message=Message(role="assistant", content=response.choices[0].message.content),
            usage=Usage(
                prompt_tokens=response.usage.prompt_tokens,
                completion_tokens=response.usage.completion_tokens
            )
        )
```

## 三、框架无关性设计

### 3.1 适配目标

系统需要支持的主流 Agent 框架：

| 框架类型 | 代表框架 | 适配要求 |
|---------|---------|---------|
| 自主框架 | LangChain、AutoGen | 通过标准适配器 |
| 对话框架 | RAG 系统、客服机器人 | 通过对话接口适配 |
| 工作流框架 | 自定义工作流引擎 | 通过工作流接口适配 |
| 执行框架 | 机器人流程自动化 | 通过执行器接口适配 |

### 3.2 Agent 执行器接口抽象

```python
class AgentExecutor(ABC):
    """Agent 执行器抽象基类"""
    
    @abstractmethod
    def execute_action(self, action: AtomicAction) -> ActionResult:
        """
        执行单个原子动作
        参数：
            action: 原子动作
        返回：
            ActionResult: 执行结果
        """
        pass
    
    @abstractmethod
    def validate_action(self, action: AtomicAction) -> bool:
        """
        验证动作可执行性
        参数：
            action: 原子动作
        返回：
            bool: 是否可执行
        """
        pass
    
    @abstractmethod
    def get_capabilities(self) -> List[Capability]:
        """
        获取执行器能力列表
        返回：
            List[Capability]: 支持的能力列表
        """
        pass
```

### 3.3 框架适配器实现示例

#### LangChain 适配器

```python
class LangChainExecutor(AgentExecutor):
    """LangChain 框架适配器"""
    
    def __init__(self, llm_adapter: LLMAdapter):
        self.llm = self._create_langchain_llm(llm_adapter)
        self.tools = []
    
    def execute_action(self, action: AtomicAction) -> ActionResult:
        if action.type == "llm_call":
            return self._execute_llm_action(action)
        elif action.type == "tool_call":
            return self._execute_tool_action(action)
        else:
            raise UnsupportedActionError(action.type)
    
    def validate_action(self, action: AtomicAction) -> bool:
        return action.type in ["llm_call", "tool_call"]
    
    def get_capabilities(self) -> List[Capability]:
        return [
            Capability(name="llm_call", description="LLM调用能力"),
            Capability(name="tool_call", description="工具调用能力")
        ]
```

#### 自定义执行器

```python
class CustomExecutor(AgentExecutor):
    """自定义执行器适配器"""
    
    def __init__(self, custom_implementation):
        self.impl = custom_implementation
    
    def execute_action(self, action: AtomicAction) -> ActionResult:
        return self.impl.execute(action)
    
    def validate_action(self, action: AtomicAction) -> bool:
        return self.impl.can_execute(action)
    
    def get_capabilities(self) -> List[Capability]:
        return self.impl.list_capabilities()
```

### 4.3 工厂模式配置

```python
class AdapterFactory:
    """适配器工厂"""
    
    @staticmethod
    def create_llm_adapter(config: dict) -> LLMAdapter:
        adapter_type = config.get("type")
        
        if adapter_type == "openai":
            return OpenAIAdapter(
                api_key=config["api_key"],
                model=config.get("model", "gpt-4")
            )
        elif adapter_type == "anthropic":
            return AnthropicAdapter(
                api_key=config["api_key"],
                model=config.get("model", "claude-3-opus-20240229")
            )
        elif adapter_type == "openai-compatible":
            return OpenAICompatibleAdapter(
                base_url=config["base_url"],
                model=config.get("model")
            )
        else:
            raise ValueError(f"不支持的适配器类型: {adapter_type}")
    
    @staticmethod
    def create_executor(config: dict, llm_adapter: LLMAdapter) -> AgentExecutor:
        executor_type = config.get("type")
        
        if executor_type == "langchain":
            return LangChainExecutor(llm_adapter)
        elif executor_type == "custom":
            return CustomExecutor(config["implementation"])
        else:
            raise ValueError(f"不支持的执行器类型: {executor_type}")
```

## 八、备注

本规范定义了系统的模型无关性和框架无关性设计原则，通过抽象接口和依赖注入实现核心层与具体实现的解耦。所有后续开发必须遵循此规范，不得在核心层直接依赖具体实现。
