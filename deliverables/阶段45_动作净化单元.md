## 📁 交付文件

### 1. `/workspace/src/atomic_actions/action_purifier.py`

核心实现文件，包含以下功能：

#### 核心类和枚举

**`PurificationLevel` (净化级别枚举)**
- `BASIC`: 基础净化（去重、命名规范）
- `STANDARD`: 标准净化（模糊识别、多职责检测）
- `ADVANCED`: 高级净化（深度分析、优化建议）

**`IssueCategory` (问题类别枚举)**
- `VAGUE_NAME`: 模糊命名
- `AMBIGUOUS_DESCRIPTION`: 描述模糊
- `MULTIPLE_RESPONSIBILITIES`: 多职责
- `DUPLICATE_ACTION`: 重复动作
- `MISSING_INPUT_OUTPUT`: 缺少输入输出
- `INCONSISTENT_NAMING`: 命名不一致
- `LOW_ATOMICITY_SCORE`: 原子性评分低

**`ActionPurifier` (核心类)**

| 方法 | 功能描述 |
|------|----------|
| `purify_queue()` | 净化原子动作队列 |
| `_detect_duplicate_actions()` | 检测重复动作 |
| `_detect_vague_actions()` | 检测模糊动作 |
| `_detect_multi_resp_actions()` | 检测多职责动作 |
| `_detect_missing_io()` | 检测缺少输入输出 |
| `_detect_inconsistent_naming()` | 检测命名不一致 |
| `_apply_purification()` | 应用净化 |
| `get_purification_report()` | 生成净化报告 |

**便捷函数**
- `purify_atomic_queue()`: 一站式队列净化
- `get_action_quality_score()`: 获取动作质量评分

## 💡 使用示例

### 基本使用

```python

    ActionPurifier, PurificationLevel, purify_atomic_queue
)

# 创建净化器
purifier = ActionPurifier()

# 1. 净化队列

    queue=my_queue,
    level=PurificationLevel.STANDARD
)

# 2. 获取结果
purified_queue = result.purified_queue
score_improvement = result.quality_score_after - result.quality_score_before

```
