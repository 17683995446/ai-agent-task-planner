## 📁 交付文件

### 1. [src/validation/config_manager.py](file:///workspace/src/validation/config_manager.py)

核心配置管理模块，包含以下组件：

#### 核心异常类

**`ConfigValidationError`**
- 配置验证错误

**`ConfigVersionMismatchError`**
- 配置版本不匹配错误

#### 核心数据类

**`ConfigMetadata`**
- 配置元数据
- 包含版本、创建时间、更新时间、校验和等

**`ValidationRule`**
- 验证规则
- 包含字段、验证器、错误信息等

**`ValidationResult`**
- 验证结果
- 包含是否有效、错误列表、警告列表

#### 核心类

**`ConfigManager` (配置管理器)**

| 方法 | 功能描述 |
|------|----------|
| `add_validation_rule(rule)` | 添加验证规则 |
| `validate(config)` | 验证配置 |
| `load()` | 加载配置 |
| `save(config, description, author)` | 保存配置 |
| `start_auto_reload(interval)` | 启动自动重新加载 |
| `stop_auto_reload()` | 停止自动重新加载 |
| `add_change_listener(listener)` | 添加配置变更监听器 |
| `remove_change_listener(listener)` | 移除配置变更监听器 |
| `get_config()` | 获取当前配置 |
| `get_metadata()` | 获取配置元数据 |

**便捷函数**
- `create_config_manager(config_path, auto_reload)`: 快速创建管理器
- `get_validation_system_config_rules()`: 获取验证系统默认配置规则

## 🔧 核心功能特性

### 1. 配置加载与保存

```python
from validation.config_manager import create_config_manager

# 创建配置管理器
manager = create_config_manager("/path/to/config.json")

# 加载配置
config = manager.load()

# 保存配置
new_config = {
    "logger": {
        "level": "INFO",
        "console_output": True
    },
    "history": {
        "max_records": 10000,
        "cleanup_strategy": "FIFO"
    }
}
manager.save(new_config, description="更新日志级别", author="Admin")
```

### 2. 配置验证

```python
from validation.config_manager import ValidationRule

# 添加验证规则
manager.add_validation_rule(ValidationRule(
    field="logger.level",
    validator=lambda x: x in ["DEBUG", "INFO", "WARNING", "ERROR"],
    error_message="日志级别必须是 DEBUG/INFO/WARNING/ERROR",
    required=False,
    default="INFO"
))

# 验证配置
validation_result = manager.validate(new_config)
print(f"验证通过: {validation_result.valid}")
if validation_result.errors:
    print(f"错误: {validation_result.errors}")
if validation_result.warnings:
    print(f"警告: {validation_result.warnings}")
```

### 3. 配置版本管理

```python
# 每次保存自动递增版本号
manager.save(config1)  # 1.0.0
```

### 4. 配置热更新

```python
# 启动自动重新加载（检测文件变更）
manager.start_auto_reload(check_interval=5.0)  # 每5秒检查一次

# 停止自动重新加载
manager.stop_auto_reload()
```

### 5. 配置变更通知

```python
# 添加配置变更监听器
def on_config_change(config):
    print(f"配置已变更: {config}")

manager.add_change_listener(on_config_change)

# 配置保存时会自动通知所有监听器
manager.save(new_config)

# 移除监听器
manager.remove_change_listener(on_config_change)
```

## 💡 使用示例

### 场景1: 验证系统配置管理

```python
from validation.config_manager import (
    create_config_manager,
    get_validation_system_config_rules
)

# 创建配置管理器
manager = create_config_manager(
    config_path="/etc/ai_agent/config.json",
    auto_reload=True
)

# 添加默认验证规则
for rule in get_validation_system_config_rules():
    manager.add_validation_rule(rule)

# 加载或创建默认配置
config = manager.load()
if not config:
    default_config = {
        "logger": {
            "level": "INFO",
            "console_output": True
        },
        "history": {
            "max_records": 10000,
            "cleanup_strategy": "FIFO"
        },
        "validation": {
            "thresholds": {
                "match_score": 0.7,
                "drift_score": 0.3
            }
        },
        "circuit_breaker": {
            "failure_threshold": 10,
            "reset_timeout": 30.0
        }
    }
    manager.save(default_config, description="默认配置", author="System")

# 添加配置变更监听器
def apply_config(config):
    print(f"应用新配置: {config}")

manager.add_change_listener(apply_config)

# 启动自动重新加载
manager.start_auto_reload()

# 使用配置
current_config = manager.get_config()
if current_config:
    log_level = current_config["logger"]["level"]
    max_records = current_config["history"]["max_records"]
    print(f"当前日志级别: {log_level}")
    print(f"最大记录数: {max_records}")
```
