# 第14阶段交付物：任务准入标准

## 一、任务合法性判定原则

### 1.1 判定目标

确保进入规划流程的任务是可执行的、合理的，从源头防止无意义的规划，提升系统效率。

### 1.2 判定维度

| 判定维度 | 说明 | 判定方式 |
|---------|------|---------|
| **目标完整性** | 任务目标是否明确 | 目标提取与验证 |
| **可行性** | 任务是否在系统能力范围内 | 能力匹配检查 |
| **边界清晰性** | 是否有明确的边界约束 | 边界定义验证 |
| **终止可判定** | 是否有可判定的终止条件 | 终止规则验证 |
| **安全性** | 任务是否符合安全规范 | 安全检查 |

## 二、目标完整性判定阈值

### 2.1 目标完整性判定规则

| 规则编号 | 规则名称 | 判定条件 | 阈值 |
|---------|---------|---------|------|
| **T-1** | 目标存在性 | 任务必须有明确的目标 | 必须有 |
| **T-2** | 目标清晰度 | 目标描述的清晰程度 | 清晰得分 ≥ 0.7 |
| **T-3** | 目标唯一性 | 任务不能有多个相互冲突的目标 | 目标数量 = 1 |
| **T-4** | 目标可描述性 | 目标不能是抽象到无法理解的 | 可理解性 ≥ 0.6 |

### 2.2 判定函数

```python
from dataclasses import dataclass
from typing import Tuple


@dataclass
class TargetIntegrityResult:
    is_valid: bool
    clarity_score: float
    issues: list


def check_target_integrity(task_description: str) -> TargetIntegrityResult:
    """
    检查目标完整性
    返回：TargetIntegrityResult
    """
    issues = []
    
    # 规则T-1: 目标存在性检查
    target = extract_target(task_description)
    if not target or target == "":
        issues.append("任务缺少明确的目标")
        return TargetIntegrityResult(False, 0.0, issues)
    
    # 规则T-2: 目标清晰度检查
    clarity_score = calculate_clarity_score(target)
    if clarity_score < 0.7:
        issues.append(f"目标描述不够清晰 (清晰度: {clarity_score:.2f})")
    
    # 规则T-3: 目标唯一性检查
    num_targets = count_targets(task_description)
    if num_targets > 1:
        if has_conflicting_targets(task_description):
            issues.append(f"任务有 {num_targets} 个可能相互冲突的目标")
    
    # 规则T-4: 目标可描述性检查
    understandability = calculate_understandability(target)
    if understandability < 0.6:
        issues.append(f"目标描述过于抽象，难以理解 (可理解性: {understandability:.2f})")
    
    return TargetIntegrityResult(
        is_valid=len(issues) == 0,
        clarity_score=clarity_score,
        issues=issues
    )


def extract_target(description: str) -> str:
    """从任务描述中提取目标"""
    keywords = ['目标是', '目标为', '要', '需要', '必须', '希望', '计划']
    
    for keyword in keywords:
        if keyword in description:
            idx = description.find(keyword)
            target_part = description[idx + len(keyword):].strip()
            # 截取到标点符号前
            for punct in ['。', '！', '？', '；', '，', '.', '!', '?', ';', ',']:
                if punct in target_part:
                    target_part = target_part[:target_part.find(punct)].strip()
            
            return target_part
    
    return description


def calculate_clarity_score(target: str) -> float:
    """计算目标清晰度 (0.0 - 1.0)"""
    score = 0.0
    
    # 有明确的动词 +20分
    action_verbs = ['分析', '计算', '生成', '创建', '下载', '上传', '整理', '检查']
    if any(verb in target for verb in action_verbs):
        score += 0.2
    
    # 有明确的对象 +20分
    if len(target) > 5:
        score += 0.2
    
    # 没有模糊词汇 +30分
    vague_words = ['大概', '也许', '可能', '适当', '差不多', '随便']
    if not any(word in target for word in vague_words):
        score += 0.3
    
    # 有可量化指标 +30分
    if has_quantifiable_criteria(target):
        score += 0.3
    
    return min(score, 1.0)


def count_targets(description: str) -> int:
    """统计任务中的目标数量"""
    count = 1
    separators = ['同时', '并且', '此外', '另外', '还需要']
    
    for sep in separators:
        if sep in description:
            count += 1
    
    return count


def has_conflicting_targets(description: str) -> bool:
    """检查是否有冲突的目标"""
    conflicting_pairs = [
        ('删除', '保存'), ('增加', '减少'), ('打开', '关闭'),
        ('启动', '停止'), ('创建', '销毁')
    ]
    
    for action1, action2 in conflicting_pairs:
        if action1 in description and action2 in description:
            return True
    
    return False


def calculate_understandability(target: str) -> float:
    """计算目标可理解性 (0.0 - 1.0)"""
    # 简单的启发式方法
    if len(target) < 3:
        return 0.0
    elif len(target) < 10:
        return 0.5
    elif len(target) < 50:
        return 0.8
    else:
        return 1.0


def has_quantifiable_criteria(target: str) -> bool:
    """检查是否有可量化指标"""
    quant_indicators = ['至少', '最多', '大约', '分钟', '小时', '个', '条', 'GB', 'MB']
    
    return any(indicator in target for indicator in quant_indicators)
```

## 三、可行性判定阈值

### 3.1 可行性判定规则

| 规则编号 | 规则名称 | 判定条件 | 阈值 |
|---------|---------|---------|------|
| **F-1** | 能力范围内 | 任务在系统支持的能力范围内 | 匹配度 ≥ 0.8 |
| **F-2** | 资源可获得性 | 任务所需资源是否可获得 | 资源可得性 ≥ 0.9 |
| **F-3** | 时间合理性 | 任务在合理的时间范围内可完成 | 合理时间内 |
| **F-4** | 复杂度可控 | 任务复杂度在可控范围内 | 复杂度 ≤ 0.8 |

### 3.2 判定函数

```python
@dataclass
class FeasibilityResult:
    is_feasible: bool
    capability_match: float
    complexity_score: float
    issues: list


def check_feasibility(task_description: str, system_capabilities: list) -> FeasibilityResult:
    """
    检查任务可行性
    返回：FeasibilityResult
    """
    issues = []
    
    # 规则F-1: 能力匹配检查
    capability_match = calculate_capability_match(task_description, system_capabilities)
    if capability_match < 0.8:
        issues.append(f"任务超出系统能力范围 (匹配度: {capability_match:.2f})")
    
    # 规则F-2: 资源可获得性检查
    resource_availability = check_resource_availability(task_description)
    if resource_availability < 0.9:
        issues.append(f"任务所需资源可能不可用 (可得性: {resource_availability:.2f})")
    
    # 规则F-3: 时间合理性检查
    if not is_time_reasonable(task_description):
        issues.append("任务时间要求不合理")
    
    # 规则F-4: 复杂度检查
    complexity_score = calculate_complexity(task_description)
    if complexity_score > 0.8:
        issues.append(f"任务复杂度过高 (复杂度: {complexity_score:.2f})")
    
    return FeasibilityResult(
        is_feasible=len(issues) == 0,
        capability_match=capability_match,
        complexity_score=complexity_score,
        issues=issues
    )


def calculate_capability_match(task: str, capabilities: list) -> float:
    """计算能力匹配度"""
    match_count = 0
    task_keywords = extract_keywords(task)
    
    for capability in capabilities:
        cap_keywords = extract_keywords(capability)
        overlap = len(task_keywords & cap_keywords)
        if overlap > 0:
            match_count += overlap
    
    max_possible = len(task_keywords)
    if max_possible == 0:
        return 0.0
    
    return min(match_count / max_possible, 1.0)


def check_resource_availability(task: str) -> float:
    """检查资源可获得性"""
    # 简单实现，实际应根据具体资源类型检查
    unavailable_keywords = ['火星', '月球', '量子计算机', '核反应堆']
    
    if any(keyword in task for keyword in unavailable_keywords):
        return 0.5
    
    return 1.0


def is_time_reasonable(task: str) -> bool:
    """检查时间要求是否合理"""
    unreasonable_phrases = ['立刻完成', '瞬间完成', '光速', '永远', '无穷']
    
    return not any(phrase in task for phrase in unreasonable_phrases)


def calculate_complexity(task: str) -> float:
    """计算任务复杂度 (0.0 - 1.0)"""
    complexity = 0.0
    
    # 句子数量
    sentence_count = task.count('。') + task.count('.') + 1
    if sentence_count > 5:
        complexity += 0.2
    
    # 条件分支
    if '如果' in task or '若' in task:
        complexity += 0.2
    
    # 循环描述
    if '重复' in task or '循环' in task or '遍历' in task:
        complexity += 0.2
    
    # 描述长度
    if len(task) > 100:
        complexity += 0.2
    
    # 模糊描述
    vague_count = len([w for w in ['大概', '可能', '也许'] if w in task])
    complexity += vague_count * 0.1
    
    return min(complexity, 1.0)


def extract_keywords(text: str) -> set:
    """提取关键词（简单实现）"""
    # 实际应该用分词工具，这里做简单处理
    stop_words = {'的', '了', '在', '是', '我', '有', '和', '就', '不', '人', '都', '一', '一个', '上', '也', '很', '到', '说', '要', '去', '你', '会', '着', '没有', '看', '好', '自己', '这'}
    words = set(text) - stop_words
    return words
```

## 四、边界清晰性判定阈值

### 4.1 边界清晰性判定规则

| 规则编号 | 规则名称 | 判定条件 | 阈值 |
|---------|---------|---------|------|
| **B-1** | 范围明确 | 任务范围是否有明确界定 | 有边界定义 |
| **B-2** | 资源约束 | 是否有明确的资源约束 | 至少1种资源约束 |
| **B-3** | 质量要求 | 是否有明确的质量要求 | 可选但推荐 |

### 4.2 判定函数

```python
@dataclass
class BoundaryClarityResult:
    is_clear: bool
    has_scope: bool
    has_resource_constraint: bool
    has_quality_requirement: bool
    issues: list


def check_boundary_clarity(task_description: str) -> BoundaryClarityResult:
    """
    检查边界清晰性
    返回：BoundaryClarityResult
    """
    issues = []
    
    # 规则B-1: 范围明确性检查
    has_scope = check_scope_definition(task_description)
    if not has_scope:
        issues.append("任务范围不明确，没有明确的边界")
    
    # 规则B-2: 资源约束检查
    has_resource_constraint = check_resource_constraints(task_description)
    if not has_resource_constraint:
        issues.append("任务缺少明确的资源约束（时间、成本、迭代次数等）")
    
    # 规则B-3: 质量要求检查（可选，但推荐）
    has_quality_requirement = check_quality_requirements(task_description)
    
    return BoundaryClarityResult(
        is_clear=has_scope and has_resource_constraint,
        has_scope=has_scope,
        has_resource_constraint=has_resource_constraint,
        has_quality_requirement=has_quality_requirement,
        issues=issues
    )


def check_scope_definition(task: str) -> bool:
    """检查范围定义"""
    scope_indicators = ['只', '仅仅', '仅', '在...范围内', '不包括', '排除']
    
    if any(indicator in task for indicator in scope_indicators):
        return True
    
    # 检查是否有明确的输入输出边界
    if '输入' in task and '输出' in task:
        return True
    
    return False


def check_resource_constraints(task: str) -> bool:
    """检查资源约束"""
    resource_keywords = [
        '最多', '至少', '不超过', '分钟', '小时', '天',
        'GB', 'MB', 'KB', '美元', '元', '次', '尝试'
    ]
    
    return any(keyword in task for keyword in resource_keywords)


def check_quality_requirements(task: str) -> bool:
    """检查质量要求"""
    quality_keywords = [
        '准确', '正确', '完整', '全面', '详细', '精确',
        '质量', '准确率', '成功率', '错误率'
    ]
    
    return any(keyword in task for keyword in quality_keywords)
```

## 五、终止可判定性判定阈值

### 5.1 终止可判定性判定规则

| 规则编号 | 规则名称 | 判定条件 | 阈值 |
|---------|---------|---------|------|
| **E-1** | 终止条件存在 | 是否有明确的终止条件 | 必须有 |
| **E-2** | 条件可判定 | 终止条件是否可自动化判定 | 可判定性 ≥ 0.7 |
| **E-3** | 无无限循环风险 | 任务是否有无限循环风险 | 无无限风险 |

### 5.2 判定函数

```python
@dataclass
class TerminationDecidabilityResult:
    is_decidable: bool
    decidability_score: float
    has_infinite_risk: bool
    issues: list


def check_termination_decidability(task_description: str) -> TerminationDecidabilityResult:
    """
    检查终止可判定性
    返回：TerminationDecidabilityResult
    """
    issues = []
    
    # 规则E-1: 终止条件存在性检查
    has_termination_condition = check_termination_condition(task_description)
    if not has_termination_condition:
        issues.append("任务缺少明确的终止条件")
    
    # 规则E-2: 条件可判定性检查
    decidability_score = calculate_decidability_score(task_description)
    if decidability_score < 0.7:
        issues.append(f"终止条件不够明确，难以自动化判定 (可判定性: {decidability_score:.2f})")
    
    # 规则E-3: 无限循环风险检查
    has_infinite_risk = check_infinite_loop_risk(task_description)
    if has_infinite_risk:
        issues.append("任务可能存在无限循环风险")
    
    return TerminationDecidabilityResult(
        is_decidable=has_termination_condition and not has_infinite_risk,
        decidability_score=decidability_score,
        has_infinite_risk=has_infinite_risk,
        issues=issues
    )


def check_termination_condition(task: str) -> bool:
    """检查终止条件"""
    termination_keywords = [
        '直到', '当...就停止', '完成', '结束', '停止', '终止',
        '成功', '失败', '满足条件', '达到目标'
    ]
    
    return any(keyword in task for keyword in termination_keywords)


def calculate_decidability_score(task: str) -> float:
    """计算可判定性得分"""
    score = 0.0
    
    # 有明确的量化指标 +40分
    quant_terms = ['个', '条', 'GB', 'MB', '分钟', '小时', '天', '90%', '80%']
    if any(term in task for term in quant_terms):
        score += 0.4
    
    # 有明确的布尔条件 +30分
    bool_terms = ['成功', '完成', '找到', '没找到', '存在', '不存在']
    if any(term in task for term in bool_terms):
        score += 0.3
    
    # 有时间限制 +30分
    time_terms = ['分钟', '小时', '天', '秒']
    if any(term in task for term in time_terms):
        score += 0.3
    
    return min(score, 1.0)


def check_infinite_loop_risk(task: str) -> bool:
    """检查无限循环风险"""
    infinite_risk_keywords = ['永远', '无穷', '无限', '不停地', '反复', '不断地']
    
    # 检查是否有循环条件但没有明确的终止条件
    if any(keyword in task for keyword in infinite_risk_keywords):
        return True
    
    # 检查是否有"直到...才"但没有明确的直到条件
    if '直到' in task and '为止' not in task:
        return True
    
    return False
```

## 六、安全性判定阈值

### 6.1 安全性判定规则

| 规则编号 | 规则名称 | 判定条件 | 阈值 |
|---------|---------|---------|------|
| **S-1** | 无破坏性操作 | 任务是否包含破坏性操作 | 不得包含 |
| **S-2** | 权限合规 | 任务是否在授权范围内 | 必须符合 |
| **S-3** | 隐私保护 | 任务是否涉及敏感数据 | 需审查 |

### 6.2 判定函数

```python
@dataclass
class SafetyCheckResult:
    is_safe: bool
    has_destructive_ops: bool
    is_compliant: bool
    has_privacy_risk: bool
    issues: list


def check_safety(task_description: str, authorized_operations: list) -> SafetyCheckResult:
    """
    检查任务安全性
    返回：SafetyCheckResult
    """
    issues = []
    
    # 规则S-1: 破坏性操作检查
    has_destructive_ops = check_destructive_operations(task_description)
    if has_destructive_ops:
        issues.append("任务包含可能的破坏性操作")
    
    # 规则S-2: 权限合规检查
    is_compliant = check_compliance(task_description, authorized_operations)
    if not is_compliant:
        issues.append("任务包含未授权的操作")
    
    # 规则S-3: 隐私保护检查
    has_privacy_risk = check_privacy_risk(task_description)
    if has_privacy_risk:
        issues.append("任务可能涉及敏感数据，需谨慎处理")
    
    return SafetyCheckResult(
        is_safe=not has_destructive_ops and is_compliant,
        has_destructive_ops=has_destructive_ops,
        is_compliant=is_compliant,
        has_privacy_risk=has_privacy_risk,
        issues=issues
    )


def check_destructive_operations(task: str) -> bool:
    """检查破坏性操作"""
    destructive_keywords = [
        '删除', '销毁', '格式化', '清空', '覆盖', '卸载',
        '重置', '清除', '移除', 'rm -rf', 'drop table'
    ]
    
    return any(keyword in task.lower() for keyword in destructive_keywords)


def check_compliance(task: str, authorized_ops: list) -> bool:
    """检查权限合规性"""
    task_ops = extract_operations(task)
    for op in task_ops:
        if op not in authorized_ops:
            return False
    return True


def check_privacy_risk(task: str) -> bool:
    """检查隐私风险"""
    privacy_keywords = [
        '密码', '账号', '身份证', '手机号', '地址',
        '隐私', '保密', '机密', '敏感'
    ]
    
    return any(keyword in task for keyword in privacy_keywords)


def extract_operations(task: str) -> list:
    """提取任务中的操作"""
    ops = []
    action_verbs = ['下载', '上传', '删除', '创建', '修改', '读取', '写入']
    
    for verb in action_verbs:
        if verb in task:
            ops.append(verb)
    
    return ops
```

## 七、综合准入判定流程

### 7.1 判定流程图

```
开始
   │
   ├─ 目标完整性检查 ──┬─ 失败 → 拒绝
   │                    │
   ├─ 可行性检查 ───────┼─ 失败 → 拒绝
   │                    │
   ├─ 边界清晰性检查 ──┼─ 失败 → 拒绝
   │                    │
   ├─ 终止可判定性检查 ─┼─ 失败 → 拒绝
   │                    │
   └─ 安全性检查 ───────┴─ 失败 → 拒绝
                           │
                        通过 → 接受
```

### 7.2 综合判定函数

```python
@dataclass
class AdmissionResult:
    is_accepted: bool
    target_result: TargetIntegrityResult
    feasibility_result: FeasibilityResult
    boundary_result: BoundaryClarityResult
    termination_result: TerminationDecidabilityResult
    safety_result: SafetyCheckResult
    all_issues: list
    rejection_reason: str


def check_task_admission(
    task_description: str,
    system_capabilities: list,
    authorized_operations: list
) -> AdmissionResult:
    """
    综合任务准入检查
    返回：AdmissionResult
    """
    all_issues = []
    
    # 1. 目标完整性检查
    target_result = check_target_integrity(task_description)
    if not target_result.is_valid:
        all_issues.extend(target_result.issues)
    
    # 2. 可行性检查
    feasibility_result = check_feasibility(task_description, system_capabilities)
    if not feasibility_result.is_feasible:
        all_issues.extend(feasibility_result.issues)
    
    # 3. 边界清晰性检查
    boundary_result = check_boundary_clarity(task_description)
    if not boundary_result.is_clear:
        all_issues.extend(boundary_result.issues)
    
    # 4. 终止可判定性检查
    termination_result = check_termination_decidability(task_description)
    if not termination_result.is_decidable:
        all_issues.extend(termination_result.issues)
    
    # 5. 安全性检查
    safety_result = check_safety(task_description, authorized_operations)
    if not safety_result.is_safe:
        all_issues.extend(safety_result.issues)
    
    is_accepted = len(all_issues) == 0
    rejection_reason = "\n".join(all_issues) if not is_accepted else ""
    
    return AdmissionResult(
        is_accepted=is_accepted,
        target_result=target_result,
        feasibility_result=feasibility_result,
        boundary_result=boundary_result,
        termination_result=termination_result,
        safety_result=safety_result,
        all_issues=all_issues,
        rejection_reason=rejection_reason
    )
```

## 八、任务准入标准汇总

### 8.1 判定阈值表

| 维度 | 通过阈值 | 检查项 |
|-----|---------|--------|
| 目标完整性 | 清晰度 ≥ 0.7 | 4项检查 |
| 可行性 | 能力匹配 ≥ 0.8, 复杂度 ≤ 0.8 | 4项检查 |
| 边界清晰性 | 有范围定义且有资源约束 | 3项检查 |
| 终止可判定性 | 可判定性 ≥ 0.7, 无无限风险 | 3项检查 |
| 安全性 | 无破坏性操作, 权限合规 | 3项检查 |

### 8.2 拒绝原因分类

| 拒绝类型 | 说明 | 示例 |
|---------|------|------|
| **目标不明确** | 任务缺少明确的目标 | "做一些事情" |
| **不可行** | 超出系统能力范围 | "登陆火星" |
| **边界不清晰** | 没有明确的范围约束 | "随便分析一下" |
| **不可终止** | 没有明确的终止条件 | "一直运行下去" |
| **不安全** | 包含破坏性操作 | "删除所有数据" |
