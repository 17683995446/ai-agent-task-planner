## 二、终止判定引擎设计

### 2.1 核心功能

终止判定引擎的主要功能包括：
1. **成功终止条件提取**：自动识别任务完成、目标达成等成功条件
2. **失败终止条件提取**：自动识别超时、错误、异常等失败条件
3. **时间限制识别**：自动提取描述中的时间限制并转换为秒数
4. **评估逻辑生成**：自动生成条件组合的评估逻辑表达式
5. **默认值处理**：在没有明确约束时提供合理的默认终止条件

### 2.2 模块架构

```
EndRuleExtractor（终止规则提取器）
├── extract()：主提取入口
├── _extract_success_conditions()：提取成功终止条件
├── _extract_failure_conditions()：提取失败终止条件
├── _extract_time_limit()：提取时间限制
└── _generate_evaluation_logic()：生成评估逻辑
```

## 三、关键技术实现

### 3.1 成功终止条件提取

通过关键词匹配从描述中提取成功条件：
- 关键词列表："完成"、"成功"、"达到"、"实现"、"生成"、"创建"等
- 每个条件生成唯一的ID和机器可执行的check_rule
- 默认提供基于任务描述的成功条件

### 3.2 失败终止条件提取

包含多种类型的失败条件：
1. **时间限制条件**（最高优先级）：从描述中提取超时限制
2. **描述中的失败关键词**：匹配"失败"、"错误"、"异常"等
3. **迭代次数限制**：默认最大10次迭代
4. **连续错误限制**：默认连续3次错误即终止
5. **默认失败条件**：兜底的通用失败条件

### 3.3 评估逻辑生成

自动生成评估逻辑字符串，格式为：
```
success: (SC1 AND SC2 AND ...); failure: (FC1 OR FC2 OR ...)
```

## 四、使用示例

### 4.1 基本使用

```python
from task_modeling.end_rule_extractor import extract_end_rule

# 从自然语言描述中提取终止规则
description = "生成2024年度销售报告"
end_rule = extract_end_rule(description)

# 访问提取结果
print(f"成功条件数量: {len(end_rule.success_conditions)}")
print(f"失败条件数量: {len(end_rule.failure_conditions)}")
print(f"评估逻辑: {end_rule.evaluation_logic}")
```

### 4.2 完整示例

```python
from task_modeling.end_rule_extractor import EndRuleExtractor

extractor = EndRuleExtractor()

# 复杂场景
desc = "2小时内完成数据分析，超过5次迭代就停止"
end_rule = extractor.extract(desc)

# 检查是否有效
if end_rule.is_valid():
    print("终止规则有效！")
    
# 遍历成功条件
for sc in end_rule.success_conditions:
    print(f"{sc.id}: {sc.description}")
    print(f"  检查规则: {sc.check_rule}")

# 遍历失败条件（按优先级）
for fc in sorted(end_rule.failure_conditions, key=lambda x: x.priority):
    print(f"{fc.id} (优先级{fc.priority}): {fc.description}")
```
