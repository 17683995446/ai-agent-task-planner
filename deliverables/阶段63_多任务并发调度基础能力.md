## 核心功能

### 1. ConcurrentTaskScheduler 类
多任务并发调度器，提供以下核心功能：
- 多任务并发调度
- 任务队列管理
- 资源限制控制
- 任务状态监控

### 2. 关键特性

#### 并发执行
- 使用ThreadPoolExecutor实现线程池
- 支持配置最大并发工作线程数
- 自动调度任务执行

#### 任务队列
- 支持优先级队列
- 可配置最大队列大小
- 线程安全的队列操作

#### 状态监控
- 实时跟踪任务状态（pending/running/completed/failed）
- 支持查询单个任务状态
- 支持查询所有任务状态

#### 回调机制
- 支持任务完成回调
- 异常处理和日志记录

### 3. 核心方法

```python
# 提交任务
task_id = scheduler.submit_task(requirement, priority=5, callback=None)

# 获取任务状态
status = scheduler.get_task_status(task_id)

# 获取所有任务状态
all_status = scheduler.get_all_tasks_status()

# 获取统计信息
stats = scheduler.get_statistics()

# 关闭调度器
scheduler.shutdown(wait=True)
```
