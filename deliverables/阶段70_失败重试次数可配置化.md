## 核心功能

### 1. RetryConfig 配置类
```python
@dataclass
class RetryConfig:
    max_retries: int = 3                    # 最大重试次数
    retry_strategy: RetryStrategy = RetryStrategy.EXPONENTIAL
    base_delay: float = 1.0                 # 基础延迟
    max_delay: float = 60.0                 # 最大延迟
    retry_conditions: List[RetryCondition] = [RetryCondition.ALL]
    retryable_exceptions: List[Type[Exception]] = []
    jitter: bool = True                     # 随机抖动
    jitter_max: float = 0.5
```

### 2. 四种重试策略
- **FIXED**: 固定间隔重试
- **EXPONENTIAL**: 指数退避（默认）
- **LINEAR**: 线性退避
- **RANDOM**: 随机间隔

### 3. 重试条件控制
- **ALL**: 所有异常
- **TIMEOUT**: 超时异常
- **NETWORK**: 网络异常
- **VALIDATION**: 验证失败
- **CUSTOM**: 自定义异常类型

### 4. 便捷装饰器
```python
@with_retry(max_retries=3, base_delay=1.0)
def my_function():
    pass
```
