## 📁 交付文件

### 1. `/workspace/src/validation/segment_validator.py`

核心实现文件，包含以下组件：

#### 核心枚举

**`ValidationPoint` (验证点类型)**
- `PRE_SUBTASK`: 子任务级预校验
- `POST_ACTION`: 原子动作执行后校验
- `PRE_ACTION`: 原子动作执行前校验
- `MILESTONE`: 里程碑校验
- `FINAL`: 最终校验

**`ValidationResult` (验证结果)**
- `PASS`: 通过
- `FAIL`: 失败
- `WARNING`: 警告
- `SKIP`: 跳过

**`CircuitState` (熔断状态)**
- `CLOSED`: 正常（熔断器关闭）
- `OPEN`: 熔断（拒绝执行）
- `HALF_OPEN`: 半开（尝试恢复）

#### 核心数据类

**`ValidationRule`**
- 验证规则定义
- 包含验证函数和严重程度
- 可配置启用/禁用

**`ValidationCheckpoint`**
- 验证检查点
- 关联多个验证规则
- 支持超时配置

**`ValidationReport`**
- 验证报告
- 包含验证结果和详细信息
- 记录验证耗时

**`CircuitBreakerMetrics`**
- 熔断器指标
- 追踪失败/成功次数
- 支持状态转换

#### 核心类

**`SegmentValidator` (分段验证器)**

| 方法 | 功能描述 |
|------|----------|
| `create_checkpoint()` | 创建验证检查点 |
| `validate_checkpoint()` | 执行检查点验证 |
| `pre_validate_subtask()` | 子任务级预校验 |
| `post_validate_action()` | 原子动作执行后校验 |
| `_can_execute()` | 检查是否可以执行 |
| `_update_circuit_breaker()` | 更新熔断器状态 |
| `get_circuit_status()` | 获取熔断器状态 |
| `reset_circuit_breaker()` | 重置熔断器 |
| `get_validation_summary()` | 获取验证摘要 |

**便捷函数**
- `create_segment_validator()`: 创建分段验证器
- `quick_validate()`: 快速验证

## 📊 工作流程

```
原子动作队列
    ↓
子任务级预校验
├─ 依赖前置检查
├─ 输入完整性检查
└─ 目标匹配检查
    ↓
执行原子动作
    ↓
原子动作后校验
├─ 输出有效性检查
└─ 错误状态检查
    ↓
熔断器状态更新
├─ 失败计数增加
├─ 检查失败阈值
└─ 触发熔断（如需要）
    ↓
里程碑校验（可选）
    ↓
全程监控
├─ 目标偏移检测
└─ 范围越界检测
    ↓
最终校验
    ↓
收敛结果输出
```

## 💡 使用示例

### 基本使用

```python
from src.validation.segment_validator import (
    SegmentValidator,
    create_segment_validator,
    quick_validate,
    ValidationPoint
)

# 1. 创建验证器
validator = create_segment_validator(
    failure_threshold=5,      # 失败5次触发熔断
    recovery_timeout=60.0     # 60秒后尝试恢复
)

# 2. 子任务预校验
pre_report = validator.pre_validate_subtask(
    subtask_id="task_001",
    context={
        "inputs": {"data": "some_data"},
        "dependencies_ready": True
    }
)

if pre_report.is_passed():
    print("✅ 子任务预校验通过")
else:
    print(f"❌ 子任务预校验失败: {pre_report.result}")

# 3. 执行原子动作（模拟）
# ... execute action ...

# 4. 动作后校验
post_report = validator.post_validate_action(
    action_id="action_001",
    context={
        "has_output": True,
        "output_data": {...},
        "has_error": False
    }
)

if post_report.is_passed():
    print("✅ 动作后校验通过")
else:
    print(f"⚠️ 动作后校验有警告")
```

### 快速验证

```python
# 快速验证
report = quick_validate(
    validator=validator,
    validation_point=ValidationPoint.POST_ACTION,
    target_id="action_002",
    context={"has_output": True, "has_error": False}
)

print(f"验证结果: {report.result.value}")
print(f"耗时: {report.duration:.3f}s")
```
