## 📁 交付文件

### 1. `/workspace/src/atomic_actions/atomic_queue_generator.py`

核心实现文件，包含以下功能：

#### 主要类和函数

**`QueueStrategy` (枚举)**
- `TOPOLOGICAL`: 拓扑排序（依赖优先）
- `PRIORITY`: 优先级排序
- `SEQUENCE`: 原顺序排序
- `WEIGHTED`: 加权排序

**`SubtaskMapping` (数据类)**
- 子任务到原子动作的映射关系
- 记录依赖映射

**`AtomicQueueGenerator` (核心类)**

| 方法 | 功能描述 |
|------|----------|
| `subtasks_to_atomic_queue()` | 将子任务列表转换为原子动作队列 |
| `_map_subtask_to_atomics()` | 单个子任务映射为原子动作 |
| `_establish_cross_subtask_dependencies()` | 建立跨子任务依赖关系 |
| `_topological_sort()` | 拓扑排序算法（Kahn算法） |
| `validate_atomic_queue()` | 验证原子队列正确性 |
| `get_execution_plan()` | 生成执行计划 |

**便捷函数**
- `generate_atomic_queue_from_subtasks()`: 一站式生成并验证
- `get_execution_plan_from_subtasks()`: 生成执行计划

## 🔧 核心特性

### 1. 多策略排序支持

```python
# 拓扑排序（默认）
queue, mappings = generator.subtasks_to_atomic_queue(
    subtasks,
    strategy=QueueStrategy.TOPOLOGICAL
)

# 优先级排序
queue, mappings = generator.subtasks_to_atomic_queue(
    subtasks,
    strategy=QueueStrategy.PRIORITY
)
```

### 2. 依赖关系保持

- 子任务内部的依赖关系保持
- 跨子任务的依赖关系自动建立
- 支持强依赖和软依赖

### 3. 原子性验证集成

- 自动集成原子校验引擎
- 检查三大原子原则
- 提供详细的验证报告

### 4. 执行计划生成

```python
plan = generator.get_execution_plan(queue)
# 返回包含步骤、动作ID、名称、依赖等的执行计划
```

## 📊 工作流程

```
子任务列表
    ↓
逐个转换为复合动作
    ↓
拆分为原子动作序列
    ↓
继承优先级、权重、输入输出
    ↓
建立跨子任务依赖关系
    ↓
根据策略排序（拓扑/优先级/序列/加权）
    ↓
生成原子动作队列
    ↓
验证队列正确性
    ↓
输出执行计划
```

## 💡 使用示例

```python
from src.atomic_actions.atomic_queue_generator import (
    AtomicQueueGenerator,
    QueueStrategy,
    generate_atomic_queue_from_subtasks
)
from src.topology.subtask_node import SubTaskNode

# 1. 创建生成器实例
generator = AtomicQueueGenerator()

# 2. 准备子任务列表
subtasks = [
    SubTaskNode(
        node_id="subtask_1",
        name="读取数据",
        description="从数据库读取销售数据",
        priority=1
    ),
    SubTaskNode(
        node_id="subtask_2",
        name="处理数据",
        description="对销售数据进行统计分析",
        priority=2
    )
]

# 3. 建立依赖关系
subtasks[1].add_dependency("subtask_1")

# 4. 生成原子队列
queue, mappings = generator.subtasks_to_atomic_queue(
    subtasks,
    strategy=QueueStrategy.TOPOLOGICAL,
    queue_name="销售分析队列"
)

# 5. 验证队列
validation = generator.validate_atomic_queue(queue)
print(f"队列是否有效: {validation['is_valid']}")

# 6. 获取执行计划
plan = generator.get_execution_plan(queue)
for step in plan:
    print(f"步骤 {step['step']}: {step['name']}")

# 便捷方式
queue, mappings, validation = generate_atomic_queue_from_subtasks(subtasks)
```
