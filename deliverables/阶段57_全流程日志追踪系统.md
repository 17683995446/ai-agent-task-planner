## 核心功能

### 1. TraceLogger 类
全流程日志追踪器，提供以下核心功能：
- 生成唯一TaskID和TraceID
- 记录四层架构每一层的操作
- 支持父子追踪关联
- 结构化数据存储
- 可查询、可审计、可追溯

### 2. 数据结构

#### TraceRecord - 追踪记录
```python
@dataclass
class TraceRecord:
    trace_id: str              # 追踪ID
    task_id: str               # 任务ID
    parent_trace_id: Optional[str]  # 父追踪ID
    timestamp: float           # 时间戳
    level: TraceLevel          # 追踪级别
    layer: Optional[LayerType] # 层级
    operation: OperationType   # 操作类型
    operation_name: str        # 操作名称
    message: str               # 消息
    data: Dict[str, Any]       # 附加数据
    duration: Optional[float]  # 耗时
    success: bool              # 是否成功
```

#### TaskTrace - 任务完整追踪
```python
@dataclass
class TaskTrace:
    task_id: str               # 任务ID
    start_time: float          # 开始时间
    end_time: Optional[float]  # 结束时间
    duration: Optional[float]  # 总耗时
    records: List[TraceRecord] # 所有记录
    status: str                # 状态
    result: Optional[Any]      # 结果
```

### 3. 枚举类型

#### TraceLevel - 追踪级别
- `TASK` - 任务级
- `LAYER` - 层级
- `OPERATION` - 操作级
- `DETAIL` - 详情级

#### LayerType - 四层架构类型
- `MODELING` - 第一层：任务归一建模层
- `TOPOLOGY` - 第二层：拓扑依赖拆解层
- `ATOMIC` - 第三层：原子动作收敛层
- `VALIDATION` - 第四层：分段校验收敛层

#### OperationType - 操作类型
- `START` - 开始
- `INPUT` - 输入
- `PROCESS` - 处理
- `OUTPUT` - 输出
- `VALIDATE` - 验证
- `ERROR` - 错误
- `COMPLETE` - 完成

### 4. 核心方法

#### 任务管理
```python
# 创建任务
task_id = tracer.create_task(
    task_description="任务描述",
    initial_data={"key": "value"}
)

# 完成任务
task_trace = tracer.complete_task(
    task_id=task_id,
    success=True,
    result=result_data,
    message="任务完成"
)
```

#### 层级操作记录
```python
# 记录层级操作
tracer.log_layer_operation(
    task_id=task_id,
    layer=LayerType.MODELING,
    operation=OperationType.PROCESS,
    operation_name="extract_target",
    message="提取任务目标",
    data={"target": "目标"}
)
```

#### 操作追踪
```python
# 开始操作
trace_id = tracer.start_operation(
    task_id=task_id,
    layer=LayerType.VALIDATION,
    operation_name="validate_plan",
    message="开始验证"
)

# 结束操作
result = tracer.end_operation(
    trace_id=trace_id,
    success=True,
    result_data={"output": "result"},
    message="验证完成"
)
```

#### 查询和统计
```python
# 获取任务记录
records = tracer.get_task_records(task_id)

# 查询记录
results = tracer.query_records(
    task_id=task_id,
    layer=LayerType.MODELING,
    limit=50
)

# 获取统计
stats = tracer.get_statistics(task_id=task_id)

# 导出追踪
export_data = tracer.export_task_trace(task_id)
```

## 使用示例

```python
from validation.trace_logger import get_trace_logger, LayerType, OperationType

# 1. 获取追踪器
tracer = get_trace_logger(storage_path="/path/to/logs")

# 2. 创建任务
task_id = tracer.create_task(
    task_description="示例任务",
    initial_data={"input": "用户需求"}
)

# 3. 记录各层操作
tracer.log_layer_operation(
    task_id=task_id,
    layer=LayerType.MODELING,
    operation=OperationType.PROCESS,
    operation_name="extract_target",
    message="提取目标",
    data={"target": "创建网站"}
)

# 4. 完成任务
task_trace = tracer.complete_task(
    task_id=task_id,
    success=True,
    result={"plan": "完整规划"}
)

# 5. 查询和导出
stats = tracer.get_statistics(task_id=task_id)
export_data = tracer.export_task_trace(task_id)
```
