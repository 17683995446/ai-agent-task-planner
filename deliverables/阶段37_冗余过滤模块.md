## 二、核心设计

### 2.1 过滤数据结构

```
FilteredTopology（过滤后拓扑）
├── original_topology: TopologyStructure - 原始拓扑
├── original_count: int - 原始数量
├── filtered_nodes: List[SubTaskNode] - 过滤后节点
├── removed_nodes: List[FilteredNode] - 移除的节点
├── is_success: bool - 是否成功
└── final_count: int - 最终数量

FilteredNode（被过滤的节点）
├── node_id, name - 基本信息
├── reason: FilterReason - 过滤原因
├── description: str - 描述
└── alternative_nodes: Optional[List[str]] - 替代节点

FilterReason（过滤原因）
├── REDUNDANT - 冗余
├── NO_CONTRIBUTION - 无贡献
├── DUPLICATE - 重复
├── DEPENDENCY_BROKEN - 依赖断开
└── NOT_REACHABLE - 不可达
```

### 2.2 组件架构

```
RedundancyFilter（冗余过滤器）
├── filter_redundancy() - 主过滤入口
├── _identify_unreachable_nodes() - 识别不可达节点
├── _identify_duplicate_nodes() - 识别重复节点
├── _identify_no_contribution_nodes() - 识别无贡献节点
├── _filter_nodes() - 执行过滤
├── _find_node() - 查找节点
└── filtered_to_dict() - 转换为字典
```

## 三、核心功能

### 3.1 不可达节点识别

**识别策略**：
- 使用BFS从起始节点遍历
- 找出无法从起始节点到达的节点
- 这类节点永远不会被执行

**识别标准**：
- 节点不在任何从起始节点出发的路径上
- 无法通过依赖关系到达

### 3.2 重复节点识别

**识别策略**：
- 按名称和描述分组
- 找出功能完全相同的节点
- 保留第一个，标记其他为重复

**识别标准**：
- 名称相同
- 描述相同或高度相似

### 3.3 无贡献节点识别

**识别策略**：
- 识别不影响最终目标的节点
- 没有输出也不被其他节点依赖
- 除了结束节点外

**识别标准**：
- 不是结束节点
- 没有输出
- 不被任何其他节点依赖

### 3.4 完整过滤流程

1. 生成拓扑结构
2. 识别不可达节点
3. 识别重复节点
4. 识别无贡献节点
5. 执行过滤
6. 返回过滤结果

## 四、使用示例

### 4.1 基本使用

```python
from topology.redundancy_filter import RedundancyFilter, filter_task_redundancy, filter_and_get_dict
from topology.subtask_splitter import SubTaskSplitter, SplitStrategy

# 1. 拆分任务
splitter = SubTaskSplitter()
subtasks = splitter.split_task(
    "开发一个Web应用系统",
    task_id="task-webapp",
    strategy=SplitStrategy.BY_PHASE
)

# 2. 过滤冗余
filter_obj = RedundancyFilter()
filtered = filter_obj.filter_redundancy(subtasks)

# 3. 查看结果
print(f"原始数量: {filtered.original_count}")
print(f"最终数量: {filtered.final_count}")
print(f"移除数量: {filtered.original_count - filtered.final_count}")

print("\n保留的任务:")
for i, task in enumerate(filtered.filtered_nodes, 1):
    print(f"  {i}. [{task.node_id}] {task.name}")

print("\n移除的任务:")
for i, removed in enumerate(filtered.removed_nodes, 1):
    print(f"  {i}. [{removed.node_id}] {removed.name}")
    print(f"     原因: {removed.reason.value} - {removed.description}")
```

### 4.2 便捷函数使用

```python
from topology.redundancy_filter import filter_task_redundancy, filter_and_get_dict

# 使用便捷函数过滤
filtered = filter_task_redundancy(subtasks)
print(f"最终数量: {filtered.final_count}")

# 使用便捷函数并获取字典
result_dict = filter_and_get_dict(subtasks)
print(f"移除数量: {result_dict['removed_count']}")
print(f"过滤成功: {result_dict['is_success']}")
```

### 4.3 完整流程集成

```python
from topology.subtask_splitter import split_task_into_subtasks
from topology.redundancy_filter import filter_and_get_dict

# 完整流程：拆分 → 过滤冗余
task_desc = "开发一个复杂系统"

# 1. 拆分任务
subtasks = split_task_into_subtasks(task_desc, task_id="task-complex")

# 2. 过滤冗余
result_dict = filter_and_get_dict(subtasks)

# 3. 检查结果
if result_dict['is_success']:
    print("✅ 过滤成功")
    print(f"保留 {result_dict['final_count']} 个任务")
    
    if result_dict['removed_count'] > 0:
        print(f"\n移除了 {result_dict['removed_count']} 个冗余任务:")
        for removed in result_dict['removed_nodes']:
            print(f"  - [{removed['node_id']}] {removed['name']}")
            print(f"    原因: {removed['reason']}")
    
    print("\n保留的任务列表:")
    for i, node in enumerate(result_dict['retained_nodes'], 1):
        print(f"  {i}. [{node['node_id']}] {node['name']}")
```
