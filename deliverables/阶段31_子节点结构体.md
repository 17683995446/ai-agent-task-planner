## 二、数据结构设计

### 2.1 核心数据结构概览

```
SubTaskNode（子任务节点）
├── 基础信息
│   ├── node_id: str
│   ├── name: str
│   ├── description: str
│   ├── parent_task_id: Optional[str]
│   └── sequence: int
│
├── 输入输出规格
│   ├── inputs: List[InputSpec]
│   └── outputs: List[OutputSpec]
│
├── 依赖关系
│   └── dependencies: List[Dependency]
│
├── 权重与优先级
│   ├── priority: int (1-10)
│   └── weight: float
│
├── 状态管理
│   ├── status: SubTaskStatus (枚举)
│   ├── start_time: Optional[float]
│   ├── end_time: Optional[float]
│   ├── duration_estimated: Optional[float]
│   └── actual_duration: Optional[float]
│
└── 元数据
    ├── metadata: Dict[str, Any]
    ├── created_at: float
    └── updated_at: float
```

### 2.2 状态枚举定义

```python
SubTaskStatus:
    PENDING    - 待执行
    READY      - 就绪（依赖已满足）
    RUNNING    - 执行中
    COMPLETED  - 已完成
    FAILED     - 已失败
    SKIPPED    - 已跳过
```

### 2.3 依赖类型定义

```python
DependencyType:
    HARD       - 强依赖（必须完成才能执行）
    SOFT       - 软依赖（推荐但不强制）
    RECOMMENDED - 推荐依赖
```

## 三、核心功能

### 3.1 输入输出管理

- `add_input(name, type, required, description)` - 添加输入规格
- `add_output(name, type, description)` - 添加输出规格
- 支持输入来源指定（source字段）
- 支持默认值设置

### 3.2 状态管理

- `mark_started()` - 标记为开始执行
- `mark_completed()` - 标记为完成
- `mark_failed()` - 标记为失败
- `is_ready()` - 判断是否就绪
- 自动记录开始/结束时间
- 自动计算实际耗时

### 3.3 依赖管理

- `add_dependency(id, type, description)` - 添加依赖
- 支持强依赖/软依赖/推荐依赖
- 支持条件依赖

### 3.4 序列化

- `to_dict()` - 转换为字典格式
- `from_dict(data)` - 从字典创建对象
- 完整的持久化支持

## 四、使用示例

### 4.1 创建子任务节点

```python
from topology.subtask_node import SubTaskNode, SubTaskStatus, DependencyType

# 创建基本节点
node = SubTaskNode(
    node_id="subtask-001",
    name="数据预处理",
    description="对输入数据进行清洗和标准化",
    parent_task_id="task-001",
    sequence=1
)
```

### 4.2 添加输入输出

```python
# 添加输入
node.add_input("raw_data", "dict", required=True, 
               description="原始输入数据")
node.add_input("config", "dict", required=False, 
               description="配置参数")

# 添加输出
node.add_output("processed_data", "dict", 
                description="处理后的数据")
```

### 4.3 添加依赖关系

```python
# 添加强依赖
node.add_dependency("subtask-000", DependencyType.HARD,
                   "前置数据准备")
```

### 4.4 状态管理

```python
# 状态流转
print(node.status.value)  # pending

node.mark_started()
print(node.status.value)  # running

node.mark_completed()
print(node.status.value)  # completed
print(node.actual_duration)  # 实际耗时
```

### 4.5 序列化

```python
# 序列化
dict_data = node.to_dict()

# 反序列化
restored_node = SubTaskNode.from_dict(dict_data)
```
