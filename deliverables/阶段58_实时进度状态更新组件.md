## 核心功能

### 1. ProgressMonitor 类
实时进度状态监控器，提供以下核心功能：
- 跟踪任务整体进度
- 跟踪四层架构各阶段进度
- 进度回调通知机制
- 历史进度查询和统计

### 2. 数据结构

#### TaskStatus - 任务状态
- `PENDING` - 待处理
- `RUNNING` - 运行中
- `PAUSED` - 已暂停
- `COMPLETED` - 已完成
- `FAILED` - 失败
- `CANCELLED` - 已取消

#### LayerStatus - 层级状态
- `NOT_STARTED` - 未开始
- `IN_PROGRESS` - 进行中
- `COMPLETED` - 已完成
- `FAILED` - 失败

#### ProgressPhase - 进度阶段
- `MODELING` - 建模阶段
- `TOPOLOGY` - 拓扑阶段
- `ATOMIC` - 原子阶段
- `VALIDATION` - 验证阶段

#### LayerProgress - 层级进度
```python
@dataclass
class LayerProgress:
    layer: ProgressPhase
    status: LayerStatus
    progress: float = 0.0
    start_time: Optional[float] = None
    end_time: Optional[float] = None
    message: str = ""
    details: Dict[str, Any] = field(default_factory=dict)
```

#### ProgressUpdate - 进度更新
```python
@dataclass
class ProgressUpdate:
    task_id: str
    timestamp: float
    overall_progress: float
    current_phase: Optional[ProgressPhase]
    status: TaskStatus
    message: str
    layer_progress: Dict[ProgressPhase, LayerProgress]
    details: Dict[str, Any] = field(default_factory=dict)
```

### 3. 核心方法

#### 任务管理
```python
# 创建任务
monitor.create_task(task_id, task_description="任务描述")

# 设置任务状态
monitor.set_task_status(task_id, TaskStatus.COMPLETED, message="任务完成")
```

#### 层级进度更新
```python
# 更新层级进度
monitor.update_layer_progress(
    task_id=task_id,
    phase=ProgressPhase.MODELING,
    layer_status=LayerStatus.IN_PROGRESS,
    progress=0.5,
    message="解析用户需求",
    details={"some": "data"}
)
```

#### 整体进度更新
```python
# 更新整体进度
monitor.update_overall_progress(
    task_id=task_id,
    progress=0.75,
    message="进行中",
    details={"some": "data"}
)
```

#### 进度查询
```python
# 获取当前进度
current = monitor.get_current_progress(task_id)

# 获取进度历史
history = monitor.get_progress_history(task_id, limit=50)

# 获取统计信息
stats = monitor.get_statistics(task_id)
```

#### 回调机制
```python
# 注册回调
def on_progress(update: ProgressUpdate):
    print(f"进度: {update.overall_progress * 100:.1f}%")

monitor.register_callback(on_progress)
```

### 4. 进度计算
- 每个阶段权重均等（各25%）
- 整体进度 = 各阶段进度 × 权重之和
- 自动计算整体进度

## 使用示例

```python
from validation.progress_monitor import get_progress_monitor, TaskStatus, LayerStatus, ProgressPhase

# 获取监控器
monitor = get_progress_monitor()

# 定义回调
def on_progress_update(update: ProgressUpdate):
    phase_str = update.current_phase.value if update.current_phase else "None"
    print(f"进度: {update.overall_progress * 100:.1f}% | 阶段: {phase_str}")

monitor.register_callback(on_progress_update)

# 创建任务
task_id = "my_task_001"
monitor.create_task(task_id, task_description="我的任务规划")

# 更新各层进度
monitor.update_layer_progress(
    task_id=task_id,
    phase=ProgressPhase.MODELING,
    layer_status=LayerStatus.IN_PROGRESS,
    progress=0.0,
    message="开始建模阶段"
)

monitor.update_layer_progress(
    task_id=task_id,
    phase=ProgressPhase.MODELING,
    layer_status=LayerStatus.COMPLETED,
    progress=1.0,
    message="建模完成"
)

# 完成任务
monitor.set_task_status(
    task_id=task_id,
    status=TaskStatus.COMPLETED,
    message="任务完成！"
)

# 获取统计
stats = monitor.get_statistics(task_id)
print(f"总进度: {stats['overall_progress'] * 100:.1f}%")
```
