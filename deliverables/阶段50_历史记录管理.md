## 📁 交付文件

### 1. [src/validation/history_manager.py](file:///workspace/src/validation/history_manager.py)

核心历史记录管理模块，包含以下组件：

#### 核心枚举

**`CleanupStrategy` (清理策略)**
- `FIFO`: 先进先出
- `LRU`: 最近最少使用

**`ExportFormat` (导出格式)**
- `JSON`: JSON格式
- `CSV`: CSV格式

#### 核心数据类

**`HistoryConfig`**
- 历史记录配置
- 包含最大记录数、清理策略、自动清理阈值等

**`HistoryRecord`**
- 历史记录基类
- 提供字典转换接口

#### 核心类

**`HistoryManager` (历史记录管理器)**

| 方法 | 功能描述 |
|------|----------|
| `add(record)` | 添加历史记录 |
| `access(index)` | 访问记录（更新LRU顺序） |
| `get(index)` | 获取记录（不更新顺序） |
| `get_all()` | 获取所有记录 |
| `get_range(start, end)` | 获取指定范围记录 |
| `get_recent(count)` | 获取最近的N条记录 |
| `query(predicate)` | 按条件查询记录 |
| `query_by_field(field, value)` | 按字段查询（使用索引） |
| `export(format)` | 导出历史记录 |
| `import_records(data, format)` | 导入历史记录 |
| `clear()` | 清空所有记录 |
| `get_statistics()` | 获取统计信息 |

**便捷函数**
- `create_history_manager(max_records, strategy)`: 快速创建管理器

## 🔧 核心功能特性

### 1. 记录上限控制

```python
from validation.history_manager import HistoryManager, HistoryConfig, CleanupStrategy

# 创建配置
config = HistoryConfig(
    max_records=10000,           # 最多10000条记录
    cleanup_strategy=CleanupStrategy.FIFO,  # 先进先出
    auto_cleanup_threshold=0.9,  # 达到90%时自动清理
    enable_index=True            # 启用索引
)

# 创建管理器
manager = HistoryManager(config)
```

### 2. 自动清理机制

```python
# FIFO清理：删除最老的记录
manager = create_history_manager(
    max_records=1000,
    strategy=CleanupStrategy.FIFO
)

# LRU清理：删除最近最少使用的记录
manager = create_history_manager(
    max_records=1000,
    strategy=CleanupStrategy.LRU
)

# 清理会自动触发（达到阈值时）
for i in range(1500):  # 超过1000条
    manager.add({"id": i, "data": f"record_{i}"})
```

### 3. 导出功能

```python
# 导出为JSON
json_data = manager.export(ExportFormat.JSON)
print(f"JSON: {len(json_data)} 字符")

# 导出为CSV
csv_data = manager.export(ExportFormat.CSV)
print(f"CSV: {len(csv_data)} 字符")
```

### 4. 导入功能

```python
# 从JSON导入
count = manager.import_records(json_data, ExportFormat.JSON)
print(f"导入了 {count} 条记录")

# 从CSV导入
count = manager.import_records(csv_data, ExportFormat.CSV)
print(f"导入了 {count} 条记录")
```

### 5. 查询功能

```python
# 按条件查询
results = manager.query(lambda r: r.get('id', 0) > 100)

# 按字段查询（使用索引）
results = manager.query_by_field('action_id', 'action_001')

# 获取最近的10条记录
recent = manager.get_recent(10)

# 获取指定范围记录
records = manager.get_range(100, 200)
```

### 6. 统计信息

```python
stats = manager.get_statistics()
print(f"总记录数: {stats['total_records']}")
print(f"最大记录数: {stats['max_records']}")
print(f"使用率: {stats['usage_ratio']:.1%}")
print(f"清理策略: {stats['cleanup_strategy']}")

```

## 💡 使用示例

### 场景1: 验证器历史记录管理

```python
from validation.history_manager import create_history_manager, CleanupStrategy
from validation.action_post_validator import ActionPostValidator, ActionOutput

# 创建管理器（最多10000条，使用LRU策略）
history_mgr = create_history_manager(
    max_records=10000,
    strategy=CleanupStrategy.LRU
)

# 创建验证器
validator = ActionPostValidator()

# 执行验证并记录
for i in range(15000):
    output = ActionOutput(
        action_id=f"action_{i}",
        success=i % 10 != 0,  # 10%失败率
        data={"result": i}
    )
    report = validator.validate_action_output(f"action_{i}", output)
    
    # 添加到历史记录
    history_mgr.add(report.to_dict())

# 检查记录数（应该不超过10000）
print(f"历史记录数: {len(history_mgr)}")

# 导出历史记录
json_data = history_mgr.export(ExportFormat.JSON)
print(f"导出大小: {len(json_data)} 字符")

# 查询失败记录
failed = history_mgr.query_by_field('validation_status', 'error')
print(f"失败记录数: {len(failed)}")
```

### 场景2: 分段验证历史记录

```python
from validation.history_manager import HistoryManager, HistoryConfig
from validation.segment_validator import SegmentValidator

# 创建管理器
config = HistoryConfig(
    max_records=50000,
    cleanup_strategy=CleanupStrategy.FIFO
)
history = HistoryManager(config)

# 创建验证器
validator = SegmentValidator()

# 批量验证
for batch in range(100):  # 100批次
    for i in range(100):  # 每批100个
        report = validator.pre_validate_subtask(
            f"task_{batch}_{i}",
            {"inputs": {"data": f"batch{batch}_task{i}"}}
        )
        history.add(report.to_dict())

# 获取统计
stats = history.get_statistics()
print(f"总验证: {stats['total_records']}")
print(f"使用率: {stats['usage_ratio']:.1%}")

# 获取最近验证
recent = history.get_recent(10)
print(f"最近10次验证:")
for r in recent:
    print(f"  {r['checkpoint_id']}: {r['result']}")
```
