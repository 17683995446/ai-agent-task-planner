# 第43阶段交付：原子校验引擎

## 一、阶段概述

本阶段完成了第三层原子动作收敛层的第三个核心组件：原子校验引擎。该引擎能够自动执行三大原子判定条件校验，识别非原子动作，提供详细的问题报告和整改建议。

**阶段工作内容**：接入三大原子判定条件自动校验  
**交付物**：原子校验引擎  
**验收标准**：非原子动作自动识别

## 二、核心设计

### 2.1 三大原子判定条件

#### 1. 单一职责原则 (Single Responsibility)
- **定义**：每个原子动作只负责一件事情
- **检测方法**：关键词匹配、名称长度分析、职责词法分析
- **关键特征**：
  - 名称明确且简短
  - 无多职责关键词（"和"、"与"、"并且"等）
  - 输入输出清晰对应

#### 2. 无副作用原则 (Side Effect Free)
- **定义**：原子动作不应该改变外部状态，或明确声明副作用
- **检测方法**：副作用关键词匹配、动作类型分析
- **关键特征**：
  - 纯计算无状态改变
  - 有副作用的操作明确声明
  - 避免隐蔽的状态变更

#### 3. 幂等性原则 (Idempotent)
- **定义**：多次执行产生相同结果
- **检测方法**：非幂等关键词匹配
- **关键特征**：
  - 设置而非递增
  - 覆盖而非追加
  - 可安全重试

### 2.2 架构设计

```
AtomicValidator (原子校验引擎)
├── validate_atomic_action(action)
│   ├── _check_single_responsibility(action, issues)
│   ├── _check_side_effect_free(action, issues)
│   ├── _check_idempotent(action, issues)
│   ├── _check_basic_completeness(action, issues)
│   └── _check_complexity(action, issues)
│
├── validate_atomic_queue(queue)
│   └── for each action: validate_atomic_action(action)
│
├── get_validation_summary(results)
│   └── 生成校验摘要统计
│
└── _calculate_score(conditions, issues)
    └── 计算原子性评分

ValidationResult (校验结果)
├── action: AtomicAction
├── is_valid: bool
├── issues: List[ValidationIssue]
├── condition_results: Dict[AtomicCondition, bool]
├── score: float
└── suggestions: List[str]

ValidationIssue (校验问题)
├── action_id, action_name
├── issue_type: IssueType
├── severity: IssueSeverity
├── description
├── suggestion
└── metadata

IssueType (问题类型)
├── MULTIPLE_RESPONSIBILITIES   # 多职责
├── HAS_SIDE_EFFECTS            # 有副作用
├── NOT_IDEMPOTENT              # 非幂等
├── UNCLEAR_PURPOSE             # 目的不明确
├── INSUFFICIENT_INPUT_OUTPUT   # 输入输出不足
└── TOO_COMPLEX                 # 过于复杂

IssueSeverity (严重程度)
├── INFO       # 信息
├── WARNING    # 警告
├── ERROR      # 错误
└── CRITICAL   # 严重
```

## 三、核心功能

### 3.1 单一职责检测

```python
检测关键词：
- "和"、"与"、"并且"、"同时"
- "既...又"、"一方面...另一方面"
- "以及"、"包括"、"包含"

额外检查：
- 名称长度 > 30字符
- 输入输出不匹配
```

### 3.2 无副作用检测

```python
副作用关键词：
- "删除"、"修改"、"更新"、"插入"、"创建"
- "写入"、"保存"、"发送"、"发布"
- "触发"、"通知"、"改变"、"变更"

例外处理：
- DATA_WRITE、FILE_IO类型动作有副作用是预期的
```

### 3.3 幂等性检测

```python
非幂等关键词：
- "递增"、"累加"、"加1"、"每次加"
- "计数"、"计数器"
- "追加"、"添加到"、"插入到"
- "生成新"、"创建新"、"生成唯一"
```

### 3.4 完整性和复杂度检测

```python
完整性检查：
- 是否有输入定义
- 是否有输出定义
- 描述是否足够详细

复杂度检查：
- 复杂关键词（"流程"、"系统"、"模块"等）
- 输入数量 > 5个
- 描述过于宽泛
```

### 3.5 评分系统

```python
评分权重：
- 单一职责：40分
- 无副作用：30分
- 幂等性：30分

问题减分：
- CRITICAL: -30分
- ERROR: -15分
- WARNING: -5分
- INFO: 不减分

总分范围：0-100
```

## 四、API设计

### 4.1 核心方法

```python
# 单个动作校验
validate_atomic_action(action) -> ValidationResult
  # 参数: AtomicAction对象
  # 返回: 完整校验结果

# 队列校验
validate_atomic_queue(queue) -> List[ValidationResult]
  # 参数: AtomicActionQueue对象
  # 返回: 每个动作的校验结果列表

# 获取摘要
get_validation_summary(results) -> Dict
  # 参数: 校验结果列表
  # 返回: 统计摘要字典
```

### 4.2 便捷函数

```python
# 批量校验
validate_atomic_actions(actions) -> List[ValidationResult]

# 校验队列并获取摘要
validate_queue_and_summarize(queue) -> Tuple[List[ValidationResult], Dict]
```

## 五、使用示例

### 5.1 校验单个原子动作

```python
from atomic_validator import AtomicValidator
from atomic_action_struct import create_atomic_action, AtomicActionType

# 创建动作
action = create_atomic_action(
    action_id="read_config",
    name="读取配置文件",
    description="从指定路径读取配置文件",
    action_type=AtomicActionType.FILE_IO
)
action.add_input("file_path", "string", required=True)
action.add_output("config", "dict")

# 校验
validator = AtomicValidator()
result = validator.validate_atomic_action(action)

# 查看结果
print(f"是否有效: {result.is_valid}")
print(f"评分: {result.score}")

print(f"\n条件结果:")
for cond, satisfied in result.condition_results.items():
    print(f"  {cond.value}: {'✅' if satisfied else '❌'}")

print(f"\n发现的问题:")
for issue in result.issues:
    print(f"  - {issue.severity.value}: {issue.description}")
    if issue.suggestion:
        print(f"    建议: {issue.suggestion}")
```

### 5.2 校验队列

```python
from atomic_validator import validate_queue_and_summarize
from atomic_action_struct import AtomicActionQueue

queue = AtomicActionQueue(queue_id="my_queue", name="我的队列")
# ... 添加动作 ...

# 校验队列
results, summary = validate_queue_and_summarize(queue)

# 查看摘要
print(f"总动作数: {summary['total_actions']}")
print(f"有效动作: {summary['valid_actions']}")
print(f"平均评分: {summary['average_score']:.1f}")
print(f"总问题数: {summary['total_issues']}")

print("\n问题类型统计:")
for issue_type, count in summary['issues_by_type'].items():
    print(f"  - {issue_type}: {count}")

print("\n条件通过情况:")
for cond, count in summary['passed_conditions'].items():
    print(f"  - {cond}: {count}/{summary['total_actions']}")
```

### 5.3 检测多职责问题

### 5.4 使用便捷函数

```python
from atomic_validator import validate_atomic_actions

actions = [
    create_atomic_action("1", "动作1", "这是第一个动作", AtomicActionType.DATA_READ),
    create_atomic_action("2", "动作2", "处理数据", AtomicActionType.TRANSFORM),
]

```
