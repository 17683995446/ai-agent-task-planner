# 第35阶段交付：拓扑纠错模块

## 一、阶段概述

本阶段完成了第二层拓扑依赖拆解层的第五个核心组件：拓扑纠错模块。该模块能够自动检测并修复循环依赖、悬空节点等非法拓扑结构，实现非法拓扑的自动拦截和重排，确保生成的拓扑结构始终合法可用。

**阶段工作内容**：开发循环依赖、悬空节点检测拦截  
**交付物**：拓扑纠错模块  
**验收标准**：非法拓扑自动拦截重排

## 二、核心设计

### 2.1 纠错数据结构

```
CorrectedTopology（纠错后拓扑）
├── original_topology: TopologyStructure - 原始拓扑
├── corrected_topology: TopologyStructure - 纠错后拓扑
├── corrections_applied: List[CorrectionAction] - 应用的纠错操作
├── is_successful: bool - 是否成功
└── error_messages: List[str] - 错误消息

CorrectionAction（纠错操作）
├── correction_type: CorrectionType - 纠错类型
├── description: str - 描述
├── affected_nodes: List[str] - 影响的节点
└── affected_edges: List[tuple] - 影响的边

CorrectionType（纠错类型）
├── CYCLE_BREAK - 打破循环
├── DANGLING_REMOVE - 处理悬空节点
├── DEPENDENCY_REORDER - 依赖重排
└── EDGE_FIX - 边修复
```

### 2.2 组件架构

```
TopologyCorrector（拓扑纠错模块）
├── correct_topology() - 主纠错入口
├── _has_cycle_in_subtasks() - 检测循环依赖
├── _break_cycle() - 打破循环
├── _find_cycle_nodes() - 找出循环中的节点
├── _find_dangling_nodes() - 找出悬空节点
├── _handle_dangling_nodes() - 处理悬空节点
└── corrected_to_dict() - 转换为字典
```

## 三、核心功能

### 3.1 循环依赖检测与修复

**检测**：
- 使用DFS（深度优先搜索）检测循环
- 维护递归栈，在递归栈中发现已访问节点即有循环

**修复策略**：
- 优先移除软依赖（SOFT, RECOMMENDED）
- 保留强依赖（HARD）
- 找出循环中的所有节点并移除循环中的非强依赖

### 3.2 悬空节点检测与处理

**检测**：
- 找出没有任何依赖且不被任何任务依赖的节点
- 单个任务不算悬空，多任务时才算

**处理策略**：
- 前半部分的悬空节点 → 让第一个节点依赖它
- 后半部分的悬空节点 → 让它依赖最后一个节点
- 使用软依赖连接，不强制依赖

### 3.3 完整纠错流程

1. 生成原始拓扑
2. 检测循环依赖 → 如有则修复
3. 检测悬空节点 → 如有则处理
4. 重新生成纠错后的拓扑
5. 返回纠错结果

## 四、使用示例

### 4.1 基本使用

```python
from topology.topology_corrector import TopologyCorrector, correct_task_topology, correct_and_get_dict
from topology.subtask_splitter import SubTaskSplitter, SplitStrategy

# 1. 拆分任务
splitter = SubTaskSplitter()
subtasks = splitter.split_task(
    "开发一个Web应用系统",
    task_id="task-webapp",
    strategy=SplitStrategy.BY_PHASE
)

# 2. 纠错拓扑
corrector = TopologyCorrector()
corrected = corrector.correct_topology(subtasks)

# 3. 查看结果
print(f"原始拓扑有效: {corrected.original_topology.is_valid}")
print(f"纠错后拓扑有效: {corrected.corrected_topology.is_valid}")
print(f"纠错成功: {corrected.is_successful}")
print(f"纠错操作数量: {len(corrected.corrections_applied)}")

for i, action in enumerate(corrected.corrections_applied, 1):
    print(f"\n操作 {i}:")
    print(f"  类型: {action.correction_type.value}")
    print(f"  描述: {action.description}")
```

### 4.2 便捷函数使用

```python
from topology.topology_corrector import correct_task_topology, correct_and_get_dict

# 使用便捷函数纠错
corrected = correct_task_topology(subtasks)
print(f"纠错成功: {corrected.is_successful}")

# 使用便捷函数并获取字典
result_dict = correct_and_get_dict(subtasks)
print(f"纠错成功: {result_dict['is_successful']}")
print(f"拓扑排序: {result_dict['topology_order']}")
```

### 4.3 完整流程集成

```python
from topology.subtask_splitter import split_task_into_subtasks
from topology.topology_corrector import correct_and_get_dict

# 完整流程：拆分 → 纠错
task_desc = "开发一个复杂系统"

# 1. 拆分任务
subtasks = split_task_into_subtasks(task_desc, task_id="task-complex")

# 2. 纠错拓扑
result_dict = correct_and_get_dict(subtasks)

# 3. 检查并使用结果
if result_dict['is_successful']:
    print("✅ 拓扑纠错成功")
    print(f"执行顺序: {result_dict['topology_order']}")
    
    if result_dict['corrections_count'] > 0:
        print(f"\n应用了 {result_dict['corrections_count']} 个纠错操作:")
        for corr in result_dict['corrections']:
            print(f"  - {corr['description']}")
else:
    print("❌ 拓扑纠错失败")
    print(f"错误: {result_dict['error_messages']}")
```
