## 三、功能特性

### 3.1 问题检测

解析器可以自动检测以下问题：

| 问题类型 | 检测内容 | 处理方式 |
|---------|---------|---------|
| 模糊词检测 | 检测"大概"、"尽量"等模糊词 | 标记问题，建议修改 |
| 多目标检测 | 检测多个并列目标 | 标记问题，建议拆分 |
| 空输入检测 | 检测空输入 | 抛出异常 |

### 3.2 自动提取

| 提取项 | 提取方法 | 示例 |
|-------|---------|------|
| 目标 | 清理模糊词后直接使用 | "生成报告" |
| 可衡量标准 | 正则提取数字+单位 | "50页" → numeric标准 |
| 前置条件 | 关键词匹配 | "需要先..." → ConditionItem |
| 边界约束 | 正则提取时间/资源 | "5分钟" → 300秒 |
| 终止规则 | 基于目标和默认规则 | 生成成功/失败条件 |

### 3.3 错误处理

统一的错误格式：

```python
class RequirementsParseError(Exception):
    message: str      # 错误消息
    details: Dict     # 详细错误信息
```

## 四、使用示例

### 4.1 基本使用

```python
from src.task_modeling.parser import parse_task_from_description

# 解析用户需求
task, warnings = parse_task_from_description(
    '生成2024年度销售报告，50页以上，包含完整4个季度数据'
)

print(f'Task ID: {task.id}')
print(f'Target: {task.target.description}')
print(f'Status: {task.status}')
```

### 4.2 使用解析器实例

```python
from src.task_modeling.parser import TaskRequirementsParser

# 创建解析器
parser = TaskRequirementsParser()

# 解析需求
try:
    task = parser.parse('生成销售报告')
    print(f'Target: {task.target.description}')
except RequirementsParseError as e:
    print(f'解析失败: {e.message}')
    print(f'详情: {e.details}')
```
